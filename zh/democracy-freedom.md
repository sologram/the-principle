# 原理视角下的民主与自由
	
## 一、方法

本文不讨论“应然”，不参与哲学争论，不引用学术权威。  
本文只做一件事：把民主与自由还原为机制。

方法来自《事物原理》：

- 公理不可证伪，只规定术语；
- 定理需桥接才有经验内容；
- 一切概念还原为约束、选择、筛选、止损。

因此本文不做价值判断，只做结构分析。

## 二、定义

民主与自由，在本文中不按日常语义使用，而按四元组定义：

| 概念 | 定义 | 四元组位置 |
|---|---|---|
| 自由 | 正确的无知 | 承认不知道，方向正确 |
| 秩序 | 正确的已知 | 知道且知道得对 |
| 奴役 | 错误的已知 | 以为知道，其实不知道 |
| 放任 | 错误的无知 | 以为不知道，其实知道但不承认 |
| 民主 | 群体秩序 | 群体 + 正确的已知 |
| 民粹 | 群体放任 | 群体 + 错误的无知 |
| 专制 | 个体秩序 | 个体 + 正确的已知 |
| 独裁 | 个体放任 | 个体 + 错误的无知 |

## 三、民主不是自由

民主是群体秩序。  
自由是承认无知。

两者不同：

- 民主是已知侧：群体知道规则，按规则行事；
- 自由是无知侧：群体承认不知道结果，保留探索空间。

所以民主不等于自由。  
民主需要自由，但民主本身是秩序。

## 四、正确的民主

正确的民主，只有那一点点程序是已知的。

已知的是：

- 投票规则；
- 任期；
- 计票方式；
- 权力交接；
- 问责机制；
- 宪法边界。

未知的是：

- 谁会当选；
- 民意怎么变；
- 政策带来什么结果；
- 群体会做出什么选择。

所以：

> 正确的民主 = 群体秩序，但秩序被压缩到只剩程序；其余全部交给群体自由。

程序是民主里唯一被承诺和兑现的东西。  
结果不被承诺，因为结果属于无知侧。

## 五、民主是相关知识缺乏的产物

这是整篇文章的认知论根基。

如果关于结果的知识充分，就不需要授权，直接执行即可。

- 知道什么是对的 → 直接执行，不需要投票；
- 知道什么是最优的 → 直接采用，不需要授权；
- 知道什么能兑现 → 直接兑现，不需要周期。

民主之所以存在，恰恰是因为：

- 我们不知道谁会当选；
- 我们不知道政策会带来什么结果；
- 我们不知道群体偏好是什么；
- 我们不知道长期利益如何计算。

所以：

> 民主不是对知识的胜利，而是对知识缺乏的制度化应对。  
> 自由是承认无知，民主是管理无知。  
> 知识越充分，民主的必要性越低；知识越缺乏，民主的必要性越高。  
> 但民主不能取代知识。它只能在没有知识的地方，用程序止损。

这与黑格尔定理完全相容：人类社会活动至今未显示理性，即相关知识至今缺乏。  
因为知识缺乏，所以无法用科学替代政治，无法用兑现替代授权，无法用判定替代投票。  
民主是这种缺乏状态下的止损机制。

这也与爱智慧民主定律一致：哲学合法性来自大众愚昧的授权。  
“愚昧”即“未掌握形式化判定能力”，即相关知识缺乏。  
哲学如此，民主也如此。区别只在于：民主有程序，哲学没有。

## 六、民主的周期

周期不是为了保证选对，而是为了保证错误不能无限扩展。

因为：

- 集体不显示理性；
- 群体一定会犯错；
- 错误若无限扩展，系统崩溃。

周期是时间维度上的止损机制：

- 表现好，延续；
- 表现差，更换；
- 错误被限制在周期内；
- 到期强制清算。

没有周期，民主会滑向：

- 民粹：情绪授权无限扩张；
- 群体奴役：教条固化，纠错关闭；
- 独裁：个体放任无限延续。

所以周期是民主的生存条件，不是民主的装饰。

## 七、民主的限制不止周期

周期只是时间维度的止损。民主还有别的限制。

| 限制 | 类型 | 防什么 |
|---|---|---|
| 周期 | 时间 | 防错误无限扩展 |
| 法律（宪法、司法、权利、规则） | 内容 | 防民主摧毁民主，防投票越界 |
| 分权分立 | 结构 | 防授权集中 |
| 市场 | 资源 | 防权力垄断资源 |
| 科学 | 认知 | 防投票决定事实 |
| 地方分权 | 空间 | 防群体规模过大 |

### 1. 法律：内容限制

宪法、司法、权利、规则，本质都是法律的不同侧面：

| 项 | 法律中的角色 |
|---|---|
| 宪法 | 根本法，规定什么不能投票 |
| 司法 | 法律的判定机制 |
| 权利 | 法律保护的边界 |
| 规则 | 法律的形式化程序 |

它们都是已知侧的形式化判定，属于同一类限制。

宪法不是民主的产物，而是民主的限制。  
它规定什么不能投票决定。  
没有宪法，民主可以投票废除民主。

司法审查：法庭不民主，但可以推翻民主决定。  
因为法庭管已知侧，民主管未知侧。  
当民主投票侵犯已知侧（法律、权利、程序），法庭可以否决。

基本权利：有些东西不能投票决定——生命、自由、财产、言论、信仰。  
这些是民主的边界，不是民主的产物。  
没有边界，民主会滑向群体奴役：多数投票剥夺少数。

### 2. 分权分立：结构限制

法律可以写得很完美，但如果立法、行政、司法握在同一只手里，法律就是废纸。  
宪法可以规定权利，但同一只手可以修宪。  
司法可以独立，但同一只手可以换法官。  
规则可以形式化，但同一只手可以改规则。

所以：

> 法律是内容，分权分立是结构。  
> 内容可以写对，结构不对，内容无效。

分权分立防的不是某条法律被违反，而是授权集中本身。  
授权一旦集中，民主就滑向专制或独裁：

- 立法、行政、司法合一 → 个体秩序（专制）；
- 再加上无问责 → 个体放任（独裁）。

所以分权分立是民主的结构前提，不是民主的法律产物。

### 3. 市场：资源限制

市场是经济侧的分散机制。  
它限制民主对资源的直接控制。  
没有市场，民主容易滑向群体奴役或独裁：谁控制授权，谁控制资源。

### 4. 科学：认知限制

科学管兑现，不管授权。  
它规定什么可以被投票决定，什么不可以。

| 问题 | 属于 | 能否投票 |
|---|---|---|
| 事实是什么 | 科学（正确的已知） | 不能 |
| 原理是否成立 | 科学（正确的已知） | 不能 |
| 政策选哪个 | 民主（群体授权） | 能 |
| 资源怎么分 | 市场 + 民主 | 部分能 |

科学对民主说：

> 事实问题不投票。  
> 原理问题不投票。  
> 兑现问题不投票。

投票只能决定偏好，不能决定事实。

科学限制民主的三种方式：

1. **边界限制**：科学划定哪些问题属于已知侧，属于已知侧的问题，民主不能投票决定。
2. **纠错限制**：科学提供兑现检验，民主决定的政策若违反科学原理，科学提供纠错依据。
3. **降级限制**：当科学把某问题从未知变成已知，民主在该问题上的必要性降低。科学扩张 → 民主收缩。

### 5. 地方分权：空间限制

群体规模越大，集体非理性越强。  
地方分权把民主限制在可形式化的小规模。  
没有分权，民主容易滑向民粹。

## 八、民主与法庭

法庭上没有民主。

因为：

- 法庭必须已知；
- 已知侧只有秩序或奴役；
- 民主是授权，法庭是判定；
- 把授权引入判定，不是民主，是民粹。

法庭的特征是秩序或奴役：

- 秩序：法律形式化，证据严格，程序可问责；
- 奴役：法律错误，证据操纵，判决按权势。

所以：

> 民主负责授权，法庭负责判定。  
> 民主可以未知，法庭不能未知。  
> 民主有周期，法庭有审级。

## 九、民主与市场

市场是另一种知识缺乏下的制度产物。  
它与民主同源，但机制不同。

### 1. 市场是定价机制

第五公理：意义即价格。  
市场用价格聚合分散信息，完成连续定价。

| 机制 | 信息类型 | 分辨率 | 连续性 |
|---|---|---|---|
| 市场 | 支付意愿 | 高 | 连续 |
| 投票 | 偏好排序 | 低 | 离散 |

市场比投票分辨率更高，因为价格是连续信号，投票是离散信号。

### 2. 市场也是知识缺乏的产物

如果关于资源配置的知识充分，就不需要市场，直接计划即可。  
市场之所以存在，是因为：

- 不知道谁最需要什么；
- 不知道什么最稀缺；
- 不知道未来偏好如何变化；
- 不知道哪种生产技术最优。

所以：

> 市场不是对知识的胜利，而是对知识缺乏的制度化应对。  
> 与民主一样，市场不承诺结果，只承诺过程。

### 3. 市场与民主的分工

| 领域 | 机制 | 解决的问题 |
|---|---|---|
| 市场 | 定价 | 资源配置（什么） |
| 民主 | 授权 | 权力归属（谁） |

市场解决“什么被生产、被消费、被定价”。  
民主解决“谁有权决定规则”。

两者不能互相替代：

- 市场不能决定宪法；
- 民主不能决定价格。

### 4. 市场与民主的相似风险

| 风险 | 市场 | 民主 |
|---|---|---|
| 失灵 | 垄断、外部性、信息不对称 | 民粹、群体奴役、独裁 |
| 止损 | 破产、竞争、反垄断 | 周期、问责、宪法 |
| 正义标准 | 效率 = 收益/成本 | 效率 = 收益/成本 |

两者都按第四公理接受效率检验。  
两者都不天然正义，都必须用效率证明自己。

### 5. 市场与民主的相互支撑

- 市场需要民主提供产权保护和契约执行；
- 民主需要市场提供资源分散和权力制衡；
- 没有市场的民主容易滑向群体奴役；
- 没有民主的市场容易滑向独裁。

所以：

> 市场是经济侧的定价机制，民主是政治侧的授权机制。  
> 两者同源：都是知识缺乏下的止损机制。  
> 两者同标：都接受效率检验。  
> 两者互补：市场防权力集中，民主防资源垄断。

## 十、自由的位置

自由是承认无知。

自由不是权利，是约束最少。  
自由不是民主，是民主的前提。

自由在民主中的位置：

- 结果属于自由侧；
- 政策属于自由侧；
- 人选属于自由侧；
- 民意变化属于自由侧。

自由在市场中的位置：

- 价格属于自由侧；
- 交易属于自由侧；
- 创新属于自由侧；
- 偏好变化属于自由侧。

自由是民主与市场的共同前提。  
没有自由，民主僵化为群体奴役，市场僵化为计划经济；  
只有自由，民主滑向民粹，市场滑向垄断。

## 十一、民主的正义

正义 = 效率 = 收益/成本。

民主是否正义，取决于它在给定约束下是否实现更高收益/成本。  
市场是否正义，同样取决于效率。

民主不是天然正义，市场也不是。  
两者都必须用效率证明自己。

如果民主长期非效率，它会在筛选过程中被淘汰，或被迫向专制、独裁演化。  
如果市场长期非效率，它会在筛选过程中被淘汰，或被迫向计划经济演化。

## 十二、动态漂移

民主不是静态的，它会漂移：

| 漂移方向 | 条件 | 结果 |
|---|---|---|
| 民主 → 群体自由 | 承认无知，开放探索 | 活力增强 |
| 民主 → 民粹 | 放弃形式化判定 | 情绪授权 |
| 民主 → 群体奴役 | 把已知教条化 | 纠错关闭 |
| 民主 → 专制 | 个体秩序接管 | 决策集中 |
| 民主 → 独裁 | 个体放任接管 | 规则虚设 |

市场同样漂移：

| 漂移方向 | 条件 | 结果 |
|---|---|---|
| 市场 → 自由竞争 | 开放准入，信息透明 | 效率提升 |
| 市场 → 垄断 | 准入关闭，信息不对称 | 效率下降 |
| 市场 → 计划 | 价格管制，产权模糊 | 信号失灵 |
| 市场 → 奴役 | 强制交易，人身依附 | 自由消失 |

漂移不靠道德判断，靠机制条件。

## 十三、结论

> 民主 = 群体秩序 = 群体 + 正确的已知。  
> 正确的民主，是只把程序当作已知，把结果留给无知。  
> 自由 = 正确的无知 = 承认不知道，方向正确。  
> 民主是相关知识缺乏的产物：知识越充分，民主越不必要。  
> 市场也是知识缺乏的产物：知识越充分，市场越不必要。  
> 民主负责授权，市场负责定价。  
> 两者同源：都是知识缺乏下的止损机制。  
> 两者同标：都接受效率检验。  
> 两者互补：市场防权力集中，民主防资源垄断。  
> 民主需要自由来纠错，需要周期来止损，需要形式化判定来防民粹。  
> 市场需要自由来定价，需要竞争来止损，需要形式化规则来防垄断。  
> 民主不承诺结果，只承诺程序。  
> 市场不承诺结果，只承诺过程。  
> 结果交给自由，纠错交给周期，筛选交给时间。

这不是价值观，这是操作系统。
