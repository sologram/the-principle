# 第二（意图）公理

## 正文

**第二公理：事物趋完备。**

> **在存在变异与筛选的系统中，不完备的结构倾向于被替换、被修正、被剪除；相对完备的结构倾向于被保留、被复制、被传播。**

**日常锚点：亡羊补牢。** 羊跑了——边界泄漏暴露；补牢——调整边界，即补漏洞；不再丢——趋完备。个体学习的同构说法是"吃一堑长一智"：错误存在暴露之后，边界被重划。这是"事物趋完备"的朴素语义直觉面，不脱离人类日常经验。

**公理定位。** 第二公理是元科学的**动力学判据**，三段论的第三环：

> 第零公理（**存在入口**：主词、边界）→ 第一公理（**正确判定**：完备）→ 第二公理（**趋近方向**：动力学）。

第零公理回答"有什么"，第一公理回答"什么是对的"，第二公理回答"会往哪里走"。没有第二公理，体系只是静态的公理集合；有了它，体系开始运动，能够解释演化、进步、学习与选择。纲要名"意图公理"：**内容名是"事物趋完备"，动力学名是"意图"（定向趋势）**——"意图"的去目的论读法见注释 1。

**核心含义："趋"不是"已"。** 本公理不声称事物已经完备——"现实总是不完美的"（纲要问答）；它声称事物在演化中呈现**向完备收敛的倾向**。类比："重力使物体下落"不等于"所有物体都已落地"；"生命趋向适应"不等于"生命已完美适应"。

注意这是统计趋势陈述：说哪类状态留存，不说增长率。逐案判完备是二值的（第一公理：边界内完备即正确），趋势是历时的——单条轨迹不必单调，局部倒退、停滞皆可能发生（如知识的黑暗时期），但高完备状态的占据倾向随时间增长。

**适用条件与无标度。** 趋完备在任何满足以下三条件的系统中成立：

| 条件 | 说明 |
|---|---|
| 可复制性 | 状态可被复制 / 传递 |
| 可变性 | 复制中可产生变异 |
| 选择性 | 不同状态有不同留存概率 |

基因、模因、技术、制度、算法、科学理论、市场皆在列。**公理无标度**：趋势不含尺度参数，对任何尺度、任何表达空间（物质的弱表达与意识的强表达）皆适用。

**泛化来源：达尔文主义。** 变异、筛选、遗传三要素抽象掉生物载体，即得上式。自然选择只是完备趋近的一个实例化机制。适应度的定义由第一公理给出：

> **适应度 = 相对环境问题（边界 B）的判断所需已被全部表达 = 相对完备。**

"相对完备"指：对指定边界 B，判断所需已表达（第一公理的完备判据，逐案二值）；跨边界的比较是工程层的排序（见剪枝定理），不进定义层。

**与第一公理的闭环。**

> 第一公理定义完备 = 正确；第二公理描述事物趋向完备；因此观察到的事物倾向于正确。

第一公理把"正确"定为判据，本公理提供动力学过程：不完备的结构被淘汰，完备的结构被留存——于是世界呈现"趋向正确"的图景。**判据与趋势的统一**：前者给静态标准，后者给历时方向。

**机制链。**

> 不完备 → 信息阻塞（博弈定理：动荡源自信息阻塞）→ 动荡 → 筛选 → 趋完备。

动荡不是噪声，是筛选压的来源；没有动荡，选择停滞。信息阻塞在博弈中持续，动荡迫使边界重划——公理 1 至 3 在此缝成一个反馈环。

**达尔文边界原理与剪枝定理。**

> **达尔文边界原理：调整事物边界，是向完备演进的有效手段。**

"现实总是不完美的——所以需要切割现实发现完备"（纲要问答）：发现完备靠切割边界，不只是等筛选。"亡羊补牢"的"补"、第一公理的"补漏洞"、达尔文的"调整边界"，是同一工程的三种说法。

**剪枝定理**：高效的探索工程，必须剪除：不完备的"正确"，不无知的"自由"，不效率的"正义"，无价格的"意义"，以及无目的的"演化"。剪除属**工程层**——原理是法庭，法庭之外的秩序还需要派出大量警察甚至军队；原理判定，工程剪枝。本公理提供方向：既然事物趋完备，剪除不完备部分即顺应演化方向。防退化照旧：按主题剪，不按难易剪（难易即边界混淆）；冻结剪枝即违背本公理。

**自指与无标度。** 本公理自指，适用于自身：

> **科学层**：事物趋完备（内容不变，科学永恒定律）。**文本层**：原理文本是事物，故文本趋完备——承诺有更优即吸收（纲要问答）。

禁止可变自指：演化的是边界与文本表述，不是"完备"的定义（定义归第一公理，见自指定理）。"科学原理不得变化"与"有更优即吸收"不冲突：这是"科学"与"科学的人类文本"的关系。

**验例表。**

| 演替 | 不完备形态 | 边界动作 |
|---|---|---|
| 地心说 → 日心说 | 本轮堆积，补丁式泄漏 | 切割重划 |
| 牛顿力学 → 相对论 / 量子力学 | 高速、微观域失效（泄漏到适用域外） | 适用域重划 |
| 燃素说 → 氧化说 | 负重量的特设补丁 | 概念边界重划 |
| 证伪事件 | 理论边界破口暴露 | 剪枝（工程层），边界更精确划定 |

证伪不等于"完全错误"：牛顿力学在低速宏观域仍相对完备。证伪是**筛选不完备理论的机制**，属工程层剪枝，不属原理判定——爱智慧边界定律：从不确定到确定，是哲学与科学的边界，证伪即边界确定化。

**小结。** 第二公理做三件事：

1. **注入动力学**：静态公理体系转为动态演化框架，能解释变化、进步与选择；
2. **抽象达尔文主义**：变异—筛选—遗传的一般逻辑跨自然、社会、形式、元科学四域成立；
3. **连接判据与趋势**：第一公理定义正确，第二公理事物向它去——判据与趋势统一。

## 注释

### 1. 意图：去目的论的定向趋势

"意图"是动力学名，不是目的论断言：

- 生物体"意图"生存繁殖——只需选择压，不需意识；
- 科学理论"意图"解释更多现象——只需筛选机制，不需目的论；
- 市场"意图"出清——只需价格机制，不需中央规划。

> **无意识、无目的、无设计者的系统，因选择压表现出定向趋优；宏观效果等价于"意图"。**

"目的"从形而上学中解放，还原为选择动力学的产物。与剪枝定理会师：剪枝要剪"**无目的的演化**"——无目的 = 无趋完备方向的变异流（噪声），正是剪枝对象。故"意图"不是比喻免责声明，而是定理词汇的同名会师。

### 2. 形式化：趋势不是度量

完备（第一公理）是**闭合条件**（边界内二值），不是标量；跨边界的"更完备 / 相对完备"是**工程层的排序**，用于剪枝与择优——纲要先例："博弈求解器 = 效率标注源"（猜想区）。任何完备性度量函数（如 C: Ω → [0,1]）只能是工程层标注源，不得进入定义层；"绝大多数初始状态"之类陈述需要测度定义，未定义前不算数。可信任的演绎必须基于公理：形式化若不溯公理，只是记号。本公理的正文形式即趋势陈述（哪类状态留存），足以承担判据与方向，不需要测度。

### 3. 自由与放任：趋完备的起点不是自由

纲要四元组：**自由 = 正确的无知；秩序 = 正确的已知；奴役 = 错误的已知；放任 = 错误的无知。** 自由在正确象限：无知被正确表达（哪些开放、由谁决断——判断所需齐全），不是缺陷。趋完备的起点是**放任**（错误的无知）与**奴役**（错误的已知）——错误存在暴露，边界重划开始。自由（正确的无知）提供变异空间；放任是被剪除对象。混淆自由与放任，会把"无知即不完备"错挂到自由头上。

### 4. 科学史与证伪的重定位

科学史是本公理最直观的经验证据：范式更替即完备性提升（验例表）。波普尔证伪主义被重新定位：**证伪不是终点，是筛选机制**——且属工程层剪枝。原理不承认证伪主义为划界标准（科学哲学自己都不坚持了）；划界正判据是承诺 / 兑现双轴，证伪在体系内的合法身份是"边界确定化"（爱智慧边界定律）。

### 5. 熵增类比的澄清

统计类比只借"宏观趋势确定、微观轨迹任意"这一点。完备性上升与热力学熵增**不同轴**：完备 = 判定闭合（判据侧），熵 = 微观态计数（热力学）；同一系统可并存。第四公理的泛化来源是最大熵原理（推断意义的熵），与本公理不冲突——一个是推断的无偏基准，一个是演化的方向，各管各的表达空间。

### 6. 黑格尔定理：趋完备的阻塞形态

**人类从历史中学到的唯一教训，就是没有从历史中吸取到任何教训 (1)。** 这是兑现链断裂的宏观表现：教训（判例）被表达，却未被吸收进边界——文本层趋完备被阻塞。它不否定本公理，而是指出阻塞机制：信息阻塞（博弈定理）可以在代际尺度上持续，筛选压失效，趋完备停滞。与本公理的自指相照：原理承诺"有更优即吸收"，正是对黑格尔定理的结构性免疫。

### 7. 与其他公理的关系

| 关联公理 | 关系 |
|---|---|
| 第零公理 | 先有存在（差异、边界），才有趋完备的对象 |
| 第一公理 | 定义完备 = 正确；本公理描述趋近该标准的动态过程。判据与趋势 |
| 第三公理 | 动荡源自信息阻塞（博弈定理）——动荡是筛选压的来源；无动荡则选择停滞 |
| 第四公理 | 自由（正确的无知）提供变异空间；放任（错误的无知）是趋完备起点 |
| 第五公理 | 效率是完备在社会科学域的投影；正义制度降低交易成本，加速趋完备 |
| 第六公理 | 价格是信息压缩机制，为方案的完备排序提供分布式标注 |
| 第七公理 | 最优是完备约束下的极值；趋完备的终极极限即最优状态 |

### 8. 应用与猜想层

- **科学进步解释**：范式更替 = 完备性提升（验例表，经验佐证）；
- **AGI 训练解读**：学习 = 假设空间中的完备搜索——应用层解读，为"为什么学习有效"提供原理级注脚；
- **对齐方向**："对齐原理而不是人类"（**猜想**）——对齐不是静态匹配，而是让机器智能沿趋完备方向演化；其行为内容依赖第三至第七公理展开，非本公理直接推论。

### 9. 小结

第二公理是体系的发动机：**事物趋完备**——变异、筛选、留存的方向性，跨尺度、跨表达空间成立。它对自身成立（文本层吸收更优，科学层内容不变），对工程给出方向（剪枝、补漏洞、调整边界），对世界给出趋势（观察到的事物倾向于正确）。判据与趋势统一：第一公理说"什么是正确的"，第二公理事物向它去。
