# 用事物原理剪枝训练数据

## 从 Perplexity 到原理驱动的数据筛选

### 一、Perplexity and Intelligence

2026 年 11 月 22 日，OpenAI 首席科学家 Jakub Pachocki 发表了文章“[Perplexity and Intelligence](https://openai.com/index/perplexity-and-intelligence/)”，讨论 Perplexity（困惑度）与人工智能发展的关系。

文章提出了一个值得关注的观察视角：语言模型的智能进步，可以通过其预测和压缩数据的能力来衡量。

Perplexity 是衡量语言模型预测能力的重要指标。对于包含 $N$ 个 token 的数据集，其定义为：

$$
PP(D,M)=
\exp\left(
-\frac{1}{N}
\sum_{i=1}^{N}
\log P_M(x_i\mid x_{<i})
\right)
$$

其中，$D$ 是评估数据集，$M$ 是模型，$x_i$ 是第 $i$ 个 token。

Perplexity 越低，意味着模型对数据集中下一个 token 的预测越准确。

但这里有一个容易被忽略的事实：

**Perplexity 不是模型自身的绝对属性，而是模型与数据集之间的关系量。**

同一个模型，在不同数据集上可能得到完全不同的 Perplexity；不同模型的 Perplexity，也只有在统一评估数据集和计算条件下才具有直接比较的意义。

因此，模型的 Perplexity 不仅取决于模型自身的能力，也取决于数据集的内容、分布和结构。

这就引出了一个重要问题：

如果训练数据集本身存在大量错误、不完备和冗余信息，那么模型究竟是在学习知识，还是在学习这些信息的统计分布？

### 二、预测能力不等于知识质量

Perplexity 衡量的是模型对数据的预测能力，而不是数据本身的正确性。

两者之间存在明显区别：

- 错误知识可能具有很低的 Perplexity。
- 正确知识可能具有很高的 Perplexity。
- 重复表达可能降低预测误差，却不一定增加有效信息。
- 新颖知识可能提高预测难度，却可能具有很高的学习价值。

例如，一段广泛传播但事实错误的陈述，可能因为在训练数据中反复出现而容易预测。

相反，一段正确但罕见的新知识，可能因为缺乏统计样本而难以预测。

因此，单纯通过 Perplexity 筛选训练数据，存在一个根本性局限：它主要判断数据与模型已有统计能力的匹配程度，无法独立判断数据所表达的知识是否正确、完备。

这也意味着，训练数据的质量不能完全由模型自身的预测能力来定义。

我们需要一种独立于模型统计偏好的判断标准。

### 三、用剪枝定理筛选训练数据

事物原理的剪枝定理，为这个问题提供了一个新的思路。

其核心思想是：高效的探索工程，应当剪除不完备的正确、不无知的自由、不效率的正义、无价格的意义、无目的的演化，以及不必要的表达。

将其应用于训练数据，可以形成六类剪枝方向。

| 剪枝原则 | 数据中的问题 | 处理方向 |
|---|---|---|
| 正确性 | 不完备的正确 | 补全前提、条件和边界，无法修复时剪除 |
| 自由 | 不无知的自由 | 识别知识与未知的混淆，避免将未知伪装成已知 |
| 正义 | 不效率的正义 | 剪除无效、冗余的资源配置表达 |
| 意义 | 无价格的意义 | 识别缺乏实际价值的内容 |
| 意图 | 无目的的演化 | 减少无目标的重复变化和无效探索 |
| 最优 | 不必要的表达 | 合并重复内容，减少无信息增量的表达 |

这里的剪枝不是简单的文本质量过滤。

它针对的是数据所表达的知识、关系、意图和价值。

一段文字可能语法正确、表达流畅，甚至具有很低的 Perplexity，但如果其核心命题缺少必要条件，或者结论存在漏洞，仍然不应直接进入高质量训练语料。

反过来，一段文字即使表达不够流畅，只要包含重要的新知识，也不应仅仅因为语言质量较低而被删除。

剪枝的对象是无效或错误的信息结构，而不是不符合某种语言风格的文本。

### 四、从存在识别到正确性判断

数据剪枝不能从正确性判断直接开始。

首先必须确认判断对象是什么。

这涉及事物原理的第零公理：

**存在，是可感知的差异；边界，是区分关系的结构化表达；事物，是由边界确定的可感知结构。**

在训练数据处理中，对应三个基本步骤：

1. 识别样本中的事物及其边界。
2. 识别样本表达的命题、关系和条件。
3. 对识别出的对象应用完备性与正确性判断。

这里尤其需要区分三个问题：

- 样本是否存在明确的判断对象？
- 样本表达是否完备？
- 样本表达是否正确？

第零公理负责对象识别和输入准入，第一公理负责正确性判断。

不能因为某个样本暂时无法判断，就将其认定为错误。

因此，剪枝系统至少应当保留三种状态：

| 状态 | 含义 | 处理 |
|---|---|---|
| 正确 | 满足判断条件 | 保留 |
| 错误 | 存在确定性冲突 | 剪除或修复 |
| 未知 | 现有信息不足以判断 | 保留、隔离或等待补充 |

这种区分非常重要，否则剪枝系统本身就可能因为信息不完备而误删正确知识。

### 五、PRAX：从判断到工程执行

剪枝定理提供原则，PRAX 则可以提供判断接口。

PRAX 的基本用途，是判断表达与事物原理之间的关系。

将 PRAX 用于训练数据，可以形成一个相对简单的工程流程：

**原始数据 → 样本识别 → PRAX 判断 → 剪枝处置 → 训练数据集**

其中：

- 遵循原理的表达，可以保留。
- 违反原理的表达，可以根据具体公理进行修复或剪除。
- 无法判定的表达，不应被强制归入错误类别。

PRAX 不必负责所有数据质量问题。例如，格式错误、乱码、重复文件等可以交给传统的数据处理工具。

这样可以避免让一个判断器承担不必要的职责。

更重要的是，PRAX 与剪枝定理可以形成分工：

- PRAX 负责判断。
- 剪枝定理负责决定处理方向。
- 数据工程负责执行。
- 训练过程负责检验结果。

这使原理判断有机会成为训练数据基础设施的一部分。

### 六、如何验证原理剪枝的价值

这项研究不应停留在理论讨论，而应当通过训练实验验证。

建议建立四组数据集：

| 实验组 | 数据处理方式 |
|---|---|
| A | 原始数据集 |
| B | 传统数据过滤、去重 |
| C | 事物原理剪枝 |
| D | 传统过滤与事物原理剪枝结合 |

尽量保持模型架构、训练计算量、训练 token 数量和评估条件一致。

主要观察指标包括：

1. 数据保留率：剪枝之后保留多少原始数据。
2. 验证集 Perplexity：模型对独立评估数据的预测能力。
3. 通用能力：语言、知识和任务处理能力。
4. 推理能力：数学、逻辑和复杂问题处理能力。
5. 泛化能力：面对训练数据中未直接出现的知识组合和任务时的表现。
6. 训练效率：单位计算成本所获得的模型能力。

这里有两个特别重要的实验设计要求。

第一，不能只比较相同 token 数量下的结果，还应比较相同训练计算预算下的结果。因为剪枝的价值之一，就是减少无效训练成本。

第二，必须建立独立的测试集，并避免 PRAX 或剪枝规则直接接触测试集答案，否则实验结果可能受到数据污染。

如果剪枝后的数据集在更少的数据量和相同计算预算下，能够训练出泛化能力更强的模型，就说明原理剪枝具有实际价值。

如果只改善 Perplexity，却没有改善泛化能力，则说明剪枝可能主要优化了数据分布，而没有真正改善知识结构。

### 七、从数据清理到智能形成

传统数据工程主要解决数据规模、重复率、格式和统计质量问题。

原理剪枝则试图进一步解决一个更根本的问题：

**模型究竟应该学习什么？**

训练数据并不是对现实世界的完整复制，而是现实信息经过观察、表达、记录和传播之后形成的集合。

其中不可避免地包含：

- 正确知识；
- 错误知识；
- 不完整知识；
- 相互矛盾的表达；
- 重复信息；
- 无效信息；
- 尚未得到验证的新知识。

如果将这些内容不加区分地输入模型，模型就必须在训练过程中自行处理这些复杂关系。

而如果能够在训练之前，通过原理判断减少错误和无效信息，就有可能降低模型学习正确知识的成本。

这也带来一个值得研究的假设：

**模型能力的提升，不仅取决于训练数据的数量，还取决于训练数据所包含的有效信息结构。**

从这个角度看，数据剪枝不只是减少训练样本，而是在改变模型所接触的信息环境。

### 八、进一步的研究方向

如果实验能够证明原理剪枝有效，还可以继续研究三个方向。

#### 1. 递归数据剪枝

模型能力提高之后，可以利用更强的模型重新检查原始数据，发现早期判断器无法识别的问题。

由此形成：

数据剪枝 → 模型训练 → 判断能力提升 → 更高质量的数据剪枝。

这可能形成持续改善的数据迭代机制。

#### 2. 数据集的结构化表达

将训练数据从单纯的文本集合，逐渐转化为具有对象、边界、命题、关系和判断状态的结构化知识集合。

这样不仅可以提高数据质量，也可能为更高效的训练方式提供基础。

#### 3. 剪枝与表达空间演化

不同质量的数据可能对模型表达空间产生不同影响。

如果大量重复和无效表达占据训练资源，模型可能获得较强的局部统计能力，却未必能够有效形成新的关系结构。

相反，经过原理筛选的数据，可能以更少的样本提供更多有效的结构信息。

这与表达空间的维度演化问题存在直接联系，值得通过控制变量实验进一步研究。

### 结语

《Perplexity and Intelligence》提供了一个观察智能进步的重要窗口：模型能否更好地压缩和预测数据。

但预测能力并不等于知识正确性，数据的统计价值也不等于数据的实际价值。

如果训练数据本身可以通过原理进行判断和剪枝，那么模型训练就有机会从单纯追求数据规模，转向追求有效信息的质量与结构。

事物原理的剪枝定理提供了这样一种可能性：

**先判断，再保留；先剪枝，再训练。**

这并不是要用原理取代所有传统数据工程，而是为数据筛选增加一个更高层次的判断标准。

最终需要验证的，不是剪枝之后的数据集看起来是否更干净，而是：

**在相同甚至更少的训练资源下，能否形成更高效、更正确、更具泛化能力的智能系统。**
