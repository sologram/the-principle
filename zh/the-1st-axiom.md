# 第一（正确）公理

## 正文

**第一公理：正确即完备。**

> **完备 = 判断所需已被全部表达。**

**公理定位。** 第一公理是元科学的**正确性判定核心**，即"正确的形而上学"的判据条款。它规定：一个命题、系统或行为是否"正确"，不由主观偏好、权威背书或经验频率决定（主观/客观 = 分歧/一致），而由其是否**完备**决定。第零公理判定"什么可进入讨论"（存在、主词、边界），第一公理判定"进入讨论后如何认定正确"。

**核心含义。** 等价链一次写死：

> **对 = 正确 = 完备 = 判断所需已被全部表达 = 边界内无未决 = 有承诺且有兑现 = 判据在体系自身（形式）**

- **正确不是"被相信"，而是无遗漏、无矛盾、可封闭。** 不完备的命题即使暂时有效，也仍属于错误存在。
- **完备不是"包含一切"，而是判断所需已被全部表达。** 判断所需指判据侧：判据、规则、程序、判例；被判定结构本身属对象侧，由第零公理准入。检验所需的素材是外部输入，不必也不应在表达之内。
- **正确与完备等价。** 若一个系统声称正确，而判断其所需的要素未被全部表达（存在不可判定、不可解释、不可兑现的部分），则其正确性不成立。

其中：**可判定** = 有判词；**可解释** = 判据在界内；**可兑现** = 有可执行的检验。"无未决"由三者成立而得，非由穷举一切而得。

**判定规则。**

> 若系统在边界 B 内存在不可判定、不可解释或不可兑现的部分，则该系统在 B 内不正确。

等价地：

> **正确 = 边界内完备 = 判断所需已被全部表达。**

此规则**逐案适用，非统一判定算法**：哥德尔限制证明，丘奇限制算法，二者皆不限逐案裁决。完备不宣称可证尽，只宣称判据自足。这不是经验归纳，而是体系对"正确"的定义性约束。

**对偶。** 与第零公理构成表达完全性的两半：

| 公理 | 侧 | 完全性 |
|---|---|---|
| 第零：存在即可分辨、有边界、可表达 | 对象侧 | 被判定结构已被表达 → 存在 |
| 第一：完备 = 判断所需已被全部表达 | 判据侧 | 判定装置已被表达 → 完备 |

**泛化来源：理性定理。** "当人类个体获取到完全信息，其行为是确定的"。理性定理与自私定理（约束下的效用最大化）合称"理性人原理"。在本公理下它是完备定义的**行为读法**：完全信息 = 判断所需已被全部表达；行为确定 = 判定确定。若信息齐备后判定仍不确定，则所谓"正确"只是未暴露的不完备。

**自指定理。** **自指必须完备，禁止可变自指。** 本公理判定自身：其正确性 = 其判断所需是否已被全部表达——判定规则、判例、分层（科学层/文本层）、守则条款皆已表达，自我判定即结案。本公理一身两层：科学层上是绝对真理（见下），文本层上以科学承诺提出——承诺正确，承担兑现。

**绝对真理定理 (0, 1)。** 绝对真理存在——至少事物原理的第零公理和第一公理就是绝对真理；这不以人的理解与接受为条件。

**域外执法定理 (0, 1, 2, 3, 4)。** 原理不深究不存在，所以也不深究错误的事物。其"所以"由第零公理的定义代入（不存在 = 错误地存在）。**判定全称，深究有限**：对一切候审者有判词，判完即止——判词（不予立案 / 错误存在）已是全部判断所需要素，再深究不产生新判词，不是不作为，是要素已尽。剪枝与处置属工程层（剪枝定理），罚归科学世俗定律。

**自指与悖论判例。** 依自指定理，悖论句过堂如下：

| 对象 | 判词 | 去向 |
|---|---|---|
| 说谎者句（"本句为假/不存在"） | 可变自指，真值自我否定，边界混淆；作为表达结构存在，作为真值承担者不予立案 | 剔除（错误存在），且不深究 |
| 罗素式总体（"一切命题的集合"） | 无边界（"一切"非完成了的总体，逐案不构成边界） | 不予立案 |
| 哥德尔句 | 非反例，是边界修订指令：指明当前边界 B 的判定力缺口 | 不判真伪，交边界修订（达尔文边界原理，工程层） |

**哥德尔立场。** 原理依据第一公理不接受哥德尔定理，不承认其演绎逻辑和科学地位。同时这不在最大挑战面前做鸵鸟：原理启动**希尔伯特进程**，用**哥德尔世界极小化**（将数学切割成哥德尔世界 G 与希尔伯特世界 H，使 G/H → 0；此为猜想）在对方认可的系统中技术性解决哥德尔问题。不完备不是真理边界，而是当前表达空间或边界划分的工程问题：通过调整边界、增强表达、引入更优形式化，不可判定域应被压缩。**达尔文边界原理**：调整事物边界，是向完备演进的有效手段。

**剪枝定理。** 高效的探索工程，必须剪除：不完备的"正确"，不无知的"自由"，不效率的"正义"，无价格的"意义"，以及无目的的"演化"。剪除属**工程**，不属原理判定——原理是法庭，法庭之外的秩序还需要派出大量警察甚至军队。防退化：剪枝只能以主题是否在界内为准，不得以难易为准——按难易剪枝即边界混淆（难易随判定者漂移），冻结剪枝即违背第二公理。

**科学定律。**

- **科学真理定律**：科学原理必须绝对正确。
- **科学定理定律**：科学原理必须被承诺正确。
- **科学永恒定律**：科学原理不得变化。其与"有更优即吸收"不冲突：这是"科学"与"科学的人类文本"的关系——科学不变，文本可修订。
- **科学体系定律**：任何科学原理不得反对自身，也不得反对任何其他科学原理。
- **科学演绎定律**：不得以非科学演绎挑战科学。内部反例通道是开着的：你可以轻松检查反例——一个就够。
- **科学世俗定律**：科学原理不直接惩罚非科学人士及行为。

**与第二公理的关系。** 第一公理定义正确（静态判据），第二公理"事物趋完备"描述趋近正确的过程（动态趋势）：

> **第一公理定义正确；第二公理描述趋近正确的过程。**

**小结。** 第一公理完成三件事：

1. **把"正确"从主观判断变为结构性判据**：正确 = 完备 = 判断所需已被全部表达；
2. **把"完备"从理想状态变为正确性的必要条件**：闭合条件，非覆盖条件；
3. **为科学、对齐、博弈、意义提供统一约束**：任何声称正确的系统必须回答——判断其所需的要素，是否已被全部表达？若有未决，则尚未正确。

## 注释

### 1. 完备是闭合条件，不是覆盖条件

"判断所需已被全部表达"≠"包含一切"。文本不需要全知，只需要自带判断手册：判据、规则、程序、判例都在表达之内，判断不外借。这正是"形式 = 判据在体系自身"的同义重述：**完备 = 形式闭合**。与第零公理"可表达"（对象侧）构成对偶：表达的完全性是两个公理共同的骨架——对象侧先表达完（准入），判据侧再表达完（正确），这就是"正确即完备"必须排在"存在即差异"之后的原因。

### 2. 逐案适用：为什么哥德尔与丘奇都不构成碰撞

完备作为判据**逐案**适用，不需要也不承诺一个统一判定算法。哥德尔限制的是"证明"（固定、有效公理化边界内的不可证句），丘奇限制的是"统一判定程序"（不存在判定一切命题的算法）——二者都不限制逐案裁决。全称管辖在此意义上是"逐案皆可裁决"，不是把"一切"当作一个完成了的总体来管辖（后者见判例表第二行）。

### 3. 理性定理注

原文："当人类个体获取到完全信息，其行为是确定的。"边角情形（如最优项并列的决断）属决断规则问题，可读作"确定到最优集"。理性定理与自私定理合称"理性人原理"，是现代微观经济学的基石。

### 4. 循环定义防御

体系自指，且对全域定义：循环定义或论证本身并无不可，只是可能不好——但因原理对全域定义，连不好都没有。自指定理要求自指必须完备：判断自身所需的要素（判定规则、判例、分层、守则）已被全部表达，循环即闭合。

### 5. 绝对真理的双层

绝对真理定理说"不以人的理解与接受为条件"——这在完备定义下是内建的："判断所需已被全部表达"是结构状态，表达是差异结构的呈现，句中没有认知者、没有接受者。定理的独立内容是存在性断言："绝对真理存在，(0, 1) 是实例。"分层结构见第零公理注释 7：科学层断言（绝对真理），文本层手续（承诺 + 兑现 + 反例通道）。

### 6. 科学划界

**爱智慧边界定律**（罗素边界定律）：从不确定到确定，是哲学与科学的边界。**爱智慧自由定律**：哲学没有对错。原理不承认证伪主义：科学哲学自己都不坚持证伪主义了。划界的正面判据是承诺/兑现双轴（科学 = 有承诺，有兑现），不是可证伪性。

### 7. 第一价值：信用

承诺/兑现轴的产物。承诺正确而兑现者积累信用，信用是体系内的第一价值——它是"有承诺、有兑现"结构能够持续运转的计量单位。**黑格尔定理**（挂 (1)）：人类从历史中学到的唯一教训，就是没有从历史中吸取到任何教训——这是兑现链断裂的宏观表现。

### 8. 可信任的演绎必须基于公理

其判断依据必须能够追溯到明确的、稳定的基本原则（否则别跟我瞎逼逼）。这是"可解释"的追溯条款：判据在界内，且判据之判据可溯至公理。

### 9. 叠加定理

知识提取的工程方法（挂 (1)）。与剪枝定理配套：叠加提取，剪枝收敛。

### 10. 对齐：原理而不是人类

"对齐原理而不是人类"是解决幻觉的终极方案（**猜想**）。方向：以人类偏好为对齐目标，系统继承人类的不完备（矛盾、漂移、不可兑现）；以原理为目标，系统被约束到可完备、可验证、可封闭的结构上。注意它是应用/猜想，其行为内容依赖第三至第七公理的展开，不是第一公理的直接推论。

### 11. 与其他公理的关系

| 关联公理 | 关系 |
|---|---|
| 第零公理 | 先确定存在与边界，再判断判据侧是否完备；二者构成表达完全性的对偶 |
| 第二公理 | 正确由完备定义，事物趋向完备 |
| 第三公理 | 博弈动荡常由信息不完备引发 |
| 第四公理 | 自由即无知，无知即未完备信息状态 |
| 第五公理 | 正义即效率，效率依赖系统完备降低交易成本 |
| 第六公理 | 意义即价格，价格由完备选择结构决定 |
| 第七公理 | 原理即最优，最优是完备约束下的极值 |

### 12. 小结

第一公理是"正确的形而上学"的判据条款：**正确即完备，完备即判断所需已被全部表达**。它对自身成立（自指定理），对绝对真理断言成立（绝对真理定理），对域外判而不深究（域外执法定理），对悖论给出判例，对哥德尔给出立场与进程。判定之后的剪枝与处置，交给法庭之外的警察与军队。
