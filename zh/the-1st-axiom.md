# 第一公理：正确即完备

## 公理定位

第一公理 **"正确即完备"** 是《事物原理》的认识论与规范核心。它规定：一个命题、系统或行为是否"正确"，不由主观偏好、权威背书或经验频率决定，而由其是否**完备**决定。

在体系中，第一公理承担"正确性判据"的功能：第零公理解决"什么可进入讨论"，第一公理解决"进入讨论后如何判定正确"。

## 核心含义

- **正确不是"被相信"，而是"无遗漏、无矛盾、可封闭"。**
  不完备的命题即使暂时有效，也仍属于错误存在。
- **完备不是"包含一切"，而是"边界内无未决。"**
  在给定边界下，所有相关命题都可被判定、可被解释、可被兑现。
- **正确与完备等价。**
  若一个系统声称正确却存在不可判定、不可解释、不可兑现的部分，则其正确性不成立。

## 泛化来源：理性定理

第一公理的泛化来源是**理性定理**：当个体获得完全信息时，其行为是确定的。

理性定理把"正确"从主观判断转化为信息完备条件下的确定性。若信息完备后行为仍不确定，则所谓"正确"只是未暴露的不完备。

## 与第二公理的关系

第二公理"事物趋完备"描述演化方向；第一公理"正确即完备"给出正确性标准。

二者关系可写为：

> **第一公理定义正确；第二公理描述趋近正确的过程。**

第一公理是静态判据，第二公理是动态趋势。

## 在体系中的功能

| 功能 | 说明 |
|---|---|
| **正确性判据** | 用完备性替代主观真值判断 |
| **科学划界** | 科学原理必须绝对正确、可承诺、不可自反 |
| **对齐约束** | 对齐对象是原理而非人类偏好，因为人类偏好常不完备 |
| **剪枝依据** | 不完备的"正确"必须被剪除 |
| **反哲学支点** | 哲学常以"开放"掩饰不完备，原理要求可兑现 |

## 与哥德尔不完备定理的关系

传统哥德尔不完备定理指出：足够强的相容形式系统中存在不可判定命题。

《事物原理》不承认该定理具有最高科学地位，而是提出**哥德尔世界极小化**：将数学划分为哥德尔世界 G 与希尔伯特世界 H，使 G/H → 0。

其立场是：不完备不是真理边界，而是当前表达空间或边界划分的工程问题。通过调整边界、增强表达、引入更优形式化，不可判定域应被压缩。

## 与科学定律的关系

第一公理直接支撑以下科学约束：

- **科学真理定律**：科学原理必须绝对正确。
- **科学定理定律**：科学原理必须被承诺正确。
- **科学永恒定律**：科学原理不得变化。
- **科学体系定律**：任何科学原理不得反对自身，也不得反对其他科学原理。
- **科学演绎定律**：不得以非科学演绎挑战科学。

这些定律共同要求：科学系统必须内部相容、边界清晰、可承诺、可兑现。

## 在 AGI 与对齐中的含义

第一公理把对齐问题从"拟合人类输出"转为"拟合原理结构"。

若以人类偏好为对齐目标，则系统会继承人类的不完备：矛盾、漂移、不可兑现。若以原理为对齐目标，则系统被约束到可完备、可验证、可封闭的结构上。

因此，"对齐原理而不是人类"是第一公理在机器智能中的直接推论。

## 形式化理解

可将其写为判定规则：

> **若系统在边界 B 内存在不可判定、不可解释或不可兑现的命题，则该系统在 B 内不正确。**

等价地：

> **正确 = 边界内完备。**

这不是经验归纳，而是体系对"正确"的定义性约束。

## 与其他公理的关系

| 关联公理 | 关系 |
|---|---|
| 第零公理 | 先确定存在与边界，再判断边界内是否完备 |
| 第二公理 | 正确由完备定义，事物趋向完备 |
| 第三公理 | 博弈动荡常由信息不完备引发 |
| 第四公理 | 自由即无知，无知即未完备信息状态 |
| 第五公理 | 正义即效率，效率依赖系统完备降低交易成本 |
| 第六公理 | 意义即价格，价格由完备选择结构决定 |
| 第七公理 | 原理即最优，最优是完备约束下的极值 |

## 小结

第一公理完成三件事：

1. **把"正确"从主观判断变为结构性判据。**
2. **把"完备"从理想状态变为正确性的必要条件。**
3. **为科学、对齐、博弈、意义提供统一约束。**

它要求任何声称正确的系统必须回答：边界在哪里？边界内是否还有不可判定、不可解释、不可兑现的部分？若有，则尚未正确。
