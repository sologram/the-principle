# 第五（正义）公理

## 正文

**第五公理：正义即效率。**

> **正义 = 效率 = 降低互动摩擦。制度的正义度反比于社会交易成本（正义测量定理）。**

**日常锚点：亲兄弟，明算账。** 明算账 = 规则清晰 = 低成本——朴素直觉早就把"正义"与"算得清"焊在一起。辅句：**冤冤相报何时了**（冲突成本无界）、**清官难断家务事**（边界混淆 → 成本高）、**和气生财**（善 = 协作 → 降摩擦）。四句全是边界词与成本词，与"正确不得有漏洞"同型：正义的朴素语义直觉面就是"账目清明"。

**公理定位。** 第五公理是元科学的**社会判据**，六环链条的第六环：

> 第零公理（**存在入口**）→ 第一公理（**正确判定**）→ 第二公理（**趋近方向**）→ 第三公理（**多主体动力学**）→ 第四公理（**开放判据**）→ 第五公理（**社会判据**）。

它也是机制链的后段（接第三公理）：

> **不完备 → 信息阻塞 → 动荡 → 筛选 → 趋完备；阻塞 → 信息成本 → 动荡（= 高交易成本的表现）→ 制度（解阻塞、降摩擦的基础设施）→ 正义度 = 降成本能力。**

第三公理解释"为什么需要制度"（博弈产生动荡），第五公理解释"什么样的制度是好的"（降摩擦的制度正义）。

**核心含义。** 三笔拆解：

- **正义不是道德直觉，是系统层面的效率属性**：一个制度的"正义程度"由其降低交易成本、提升系统效率的能力决定。道德直觉不提供判据（爱智慧自由定律：哲学没有对错），判据在确定侧（爱智慧边界定律：从不确定到确定，是哲学与科学的边界）。
- **效率不是经济增长**：不是 GDP 或生产力指标，而是**制度效率**——制度安排降低人类互动摩擦的能力（交易成本：信息搜索、谈判、监督、执行、冲突解决）。
- **不是功利主义**："最大幸福"是不确定词（无承诺无兑现），本公理不依赖任何幸福主义假设——正义 = 降摩擦，是可检验的工程命题。

**好 = 效率。** 纲要定义区的四判据在此落地：

> **真 = 正确（第一公理）；好 = 效率（本公理）；善 = 协作（第三/五公理）；美 = 竞争力（第二/七公理）。**

由此完成对规范问题域的接管："正义不需要道德基础"的体系内根据不是哲学批判，而是**分工**——真与好各有判据（完备 / 效率），善是协作、美是竞争力，各归各的公理。"正义即效率"是元科学接管规范问题域的正确形而上学动作。

**正义测量定理。**

> **社会的正义度反比于社会交易成本。**

**正义是范畴，正义度是标注。** 正义 =（某安排是否降低互动摩擦），逐案二值（第一公理口径）；正义度（TC 的高低、TC(S) < TC(S') 的比较）是**工程层标注**（纲要先例："博弈求解器 = 效率标注源"）。度量相对边界 B（什么算"一次交易"随尺度重划——边界即尺度）。**判定规则**：若某制度声称促进"正义"但实际导致交易成本上升，则该制度不正义；改革方向是成本的单调递减——但注意目标是**可行下界，不是零**（见判例表第三行）。

**泛化来源：科斯定理。** 交易成本为零时，产权如何配置都无关（自愿谈判总达最优）；交易成本为正时，制度安排至关重要。第五公理取其第二推论：

> **正义的制度 = 降低交易成本的制度；正义的法律 = 最小化摩擦的法律。**

由此从经济学提升为一般社会规范原理：不仅经济制度，任何社会规范（法律、道德、习俗）的正义性，都取决于其降低社会交易成本的能力。科斯的产权难题（公共物品产权难界定）由**边界定理**处理：为公共物品创造可操作的边界（碳排放配额等）——事物定于边界，边界的工程化就是产权的工程化。

**治理四元组。** 民主 = 群体秩序；民粹 = 群体放任；专制 = 个体秩序；独裁 = 个体放任（定义）。四元组的轴是**秩序/放任**（组织方式），不是自由/奴役（个体状态）——两轴交叉，不互相还原。逐案的效率高低（如独裁的系统性风险）由判定给出，不入定义（效率解读见注释 5）。

**与前四公理的闭环。**

- **对第零公理**：差异产生交易需求，交易产生成本。全同主体无交易，正义问题不发生——差异是正义问题的起点。
- **对第一公理**：不完备的法律（漏洞、矛盾）导致不确定性成本——完备规则即产权明晰（科斯"产权明确界定"的前提）。第一公理判制度的"正确"，第五公理评制度的"好"：**正确的制度 = 完备且降摩擦的制度**。
- **对第三公理**：动荡 = 高交易成本的表现（"神仙打架，凡人遭殃"即冲突成本外溢）；制度是解阻塞的基础设施（信用可预期 → 谈判/监督/执行成本下降；价格压缩信息成本——第六公理）。**C_info 即解阻塞成本**——博弈定理与正义测量定理同源。
- **对第四公理**：正义的制度 = 规则正确（秩序）且保留合法开放（自由），压缩伪开放（放任）——产权/规则界定"已知"与"开放"的边界，这是第四公理的制度面。注意不是"最大化自由"（自由是范畴，不可最大化）。

**剪枝定理：剪伪正义。** 剪枝剪的"不效率的正义"，即**不以效率为形态的正义**——伪正义：声称正义、实增摩擦。与"不无知的自由 = 伪自由"同构，不是剪正义本身。特权、垄断、身份歧视是典型：以"正义"之名行"增摩擦"之实。**剪伪正义 = 降低社会交易成本**，与解阻塞、释放表达同向。

**判例表。**

| 对象 | 判词 | 去向 |
|---|---|---|
| 伪正义制度（特权、垄断、身份歧视） | 声称正义实增摩擦，不以效率为形态 | 剪枝（剪伪正义），工程层 |
| 审讯者式制度（制造放任/阻塞） | 制造阻塞 = 制造交易成本，正义度坍塌 | 判定不正义；解阻塞属工程层 |
| 零交易成本理想（科斯世界/乌托邦） | 理想化边界（与"有效市场"同型）；零 TC = 零自由同型（他方意图完全可见即全知） | 判为理想化，非现实设计目标；目标是可行下界 |

**自指与无标度。** 本公理自指，适用于自身：

> **科学层**：正义即效率（内容不变，科学永恒定律）。**文本层**：原理自身的"制度效率"可检验——判据、判例、程序降低了判断与协调的交易成本：**反例可查 = 检验成本低**（一个就够），承诺/兑现 = 信用积累（第一价值），域外执法定理 = 不纠缠于成本转嫁式争论。

反哲学即反 DDoS（问答原话）：语义漂移、逃避责任都是**成本转嫁**——把论证成本甩给对手，正是不效率的"正义"（伪正义的论辩形态）。禁止可变自指：不得用效率重新定义"正确"（判据归第一公理）——便宜的错误规则不正确；不得用"降成本"为伪正义背书。**公理无标度**：交易成本不含尺度参数——二人、组织、国家、种际、人机皆适用；表达空间物质/意识中立。

**小结。** 第五公理做三件事：

1. **将正义操作化**：道德概念 → 工程命题（降低交易成本）；**好 = 效率**的判据落地；
2. **统一制度评价**：宪法、法律、产权、市场、习俗的正义性归一为同一问题——它降低还是增加摩擦？
3. **连接判定与效果**：规范判定（正义）落回可检验的制度效果（交易成本）——判定与效果统一。

## 注释

### 1. 朴素语义锚：亲兄弟，明算账

| 日常 | 体系词 | 语义 |
|---|---|---|
| 亲兄弟，明算账 | 规则清晰 → 低成本 | 正义 = 账目清明 |
| 冤冤相报何时了 | 冲突成本无界 | 正义度坍塌的形态 |
| 清官难断家务事 | 边界混淆 → 成本高 | 与第零公理三失效挂靠 |
| 和气生财 | 善 = 协作 → 降摩擦 | 与第三公理信用桥同向 |

朴素语义的"正义"从来带着成本词与边界词——"正义即效率"不是强加，是对直觉的严格化（同"正确不得有漏洞"的待遇）。

### 2. 科斯理想与 EMH 同型

"交易成本为零时制度无关"是理想化边界，与第三公理注释 6 的"有效市场假说 = 阻塞→0"完全同型。且**零交易成本 = 零自由**（第四公理"零动荡 = 零自由"的同型）：他方意图完全可见即全知，谈判消失即选择消失。故现实目标是**可行下界**：在自由（合法开放）存在、阻塞不可归零的前提下，把摩擦压到可行的最低处。乌托邦判为理想化，不是设计目标。

### 3. TC 分量表（工程层分解）

| 分量 | 内容 | 体系对应 |
|---|---|---|
| 信息成本 | 搜索、验证、传递 | 解阻塞成本（C_info，博弈定理同源） |
| 谈判成本 | 协商、缔约 | 信用基础设施可降（第一价值） |
| 监督成本 | 执行监督、发现违约 | 价格/信用可降（第六公理） |
| 执行成本 | 强制执行、惩罚 | 工程层（法庭之外的警察） |
| 冲突成本 | 利益冲突的消耗破坏 | 动荡的外溢（神仙打架，凡人遭殃） |

这是**度量分解**（工程层），不是定义层——正义的定义在"降摩擦"（范畴），分量是测度的切法。

### 4. 哲学象限对照

功利主义（最大幸福）、康德义务论（可普遍化准则）、罗尔斯（差异原则/原初立场）、诺齐克（持有正义）是哲学象限的不确定方案：或无判据（幸福、原初立场不可兑现），或无内容（义务论只给形式不给效率评价），或忽视产权界定的成本（诺齐克）。本公理以效率（确定侧）**取代**之，不综合——爱智慧边界定律：哲学与科学的边界在确定性。对照表保留作谱系，不作调和（反哲学即反不承诺不兑现）。

电车难题式道德直觉辩论的判例：判据不在场、无可兑现检验 → 退回哲学象限（无承诺无兑现），不构成正义判定——科学划界的现场演示。

### 5. 治理四元组的效率解读（推断，非定义）

民主（群体秩序）：规则化程序降低群体决策的交易成本——决策慢，但避免暴力冲突的高昂成本。民粹（群体放任）：规则失效，情绪主导，成本飙升。专制（个体秩序）：短期决策快，系统性风险集中，长期成本（腐败、信息失真、创新抑制）高。独裁（个体放任）：无规则约束，成本最高形态。注意：**定义在四元组格（群体/个体 × 秩序/放任），效率高低是逐案判定的推断**，不入定义。

### 6. 信用与价格：解阻塞的两条基础设施

第三公理注释 5 的桥在此接完：**信用**（可预期 → 谈判/监督/执行成本下降）、**价格**（信息压缩 → 信息成本下降，第六公理）是社会降摩擦的两条主干基础设施。"亲兄弟明算账"的现代形态就是这两条：合同（信用的文本化）与市场（价格的机制化）。正义制度的工程内容 = 建设解阻塞、降摩擦的基础设施。

### 7. 法庭与 DDoS：成本控制

原理自称法庭（问答："原理是法庭，但法庭之外的秩序还需要派出大量警察甚至军队"）。域外执法定理（不深究不存在）与科学世俗定律（不惩罚非科学人士）都是**成本控制条款**：把审理成本限制在判词，不把成本耗在纠缠上。反哲学即反 DDoS——语义漂移、逃避责任是成本转嫁式的论辩（把核查成本甩给对手），正是不效率的"正义"在论辩领域的形态。

### 8. 分配正义的体系内推论

分配不公 → 动荡 → 成本上升（第三公理）→ 正义度下降。这是体系内链条（不作经验断言）：分配问题被吸收进效率判据，不需要独立的分配正义公设。注意推论只处理"分配如何影响摩擦"，不回答"应该怎样分配"——后者若超出体系判据（无可兑现检验），按爱智慧边界定律退入哲学象限。

### 9. 与其他公理的关系

| 关联公理 | 关系 |
|---|---|
| 第零公理 | 差异产生交易需求；全同主体无交易，正义问题不发生 |
| 第一公理 | 完备规则 = 产权明晰；判"正确"；第五公理评"好" |
| 第二公理 | 制度趋完备 = 降摩擦方向；文明史即成本下降史 |
| 第三公理 | 动荡 = 高交易成本的表现；制度 = 解阻塞基础设施；C_info 即解阻塞成本 |
| 第四公理 | 正义制度 = 秩序正确 + 保留合法开放；产权界定"已知/开放"边界 |
| 第六公理 | 价格压缩信息成本；意义的定价机制是降摩擦工具 |
| 第七公理 | 最优制度 = 完备约束下的极值（最小化可行摩擦） |

### 10. 应用与猜想层

- **改革方向**（应用）：简化审批、完善法治、保护产权、促进信息流通——皆降摩擦的具体化；
- **AGI 治理参考**（应用/猜想）：多 AGI 社会的治理规则设计追求最小化交互成本——标准化协议、透明规则、可执行契约；
- **制度经济学/法经济学**（工程层工具）：交易成本经济学（Williamson）、产权理论（Coase/Demsetz）、制度变迁（North）、公共选择（Buchanan）、法经济学（责任规则、合同法、宪法）——皆可作 TC 测度与制度设计的工程层工具箱。

### 11. 小结

第五公理是体系的社会判据：**正义即效率，好 = 效率**。它对自身成立（法庭成本可控、反例可查），对制度给出度量（正义度反比于交易成本，范畴 + 工程层标注），对治理给出四元组（秩序/放任轴），对伪正义给出剪枝（剪伪正义），对理想给出边界（零 TC 是理想化，不是目标）。判定与效果统一：正义不再在庙堂辩论，而在账目清明——亲兄弟，明算账。
