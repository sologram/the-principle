# 「原理桥」挖掘计划 · 路线图 v3

MiMo

> **一句话定义**：用《原理的演绎》的算子（泛化/迁移/组合），检验《表达空间的维度演化猜想》，
> 产出是"桥"，副产品是对猜想本身的证实或修正。

---

## 〇、核心概念（两篇文档的合流）

- **表达空间**：可表达的事物、关系、边界及其高阶结构构成的空间。
- **表达维度**：能够独立表达和区分事物及其关系的结构方向。
- **桥**：两个维度签名之间的结构保持映射，其产出是一次维度变化。
- **三机制算子**：泛化 / 迁移 / 组合，作用于表达空间。
- **维度变化类型**（桥的分类标签）：
  - 维度新增：出现此前无法独立表达的新区分方向
  - 维度分化：混合方向被拆开
  - 维度重组：已有维度间关系重排
  - 维度合并：旧维度被高阶理论吸收
  - 元化：表达对象上升到表达方式/生成规则本身（X → I(X)）

## 〇′、四大原则（全计划适用）

1. **表达重于演绎**——桥的质量取决于维度签名的表达质量。
2. **正向产桥，反向杀桥**——双闭环特化还原是核心质检。
3. **桥接前提必须显式**——宁可 `axiom` 丑，不许隐含假设藏。
4. **廉价淘汰，昂贵认证**——噪声桥用半形式化手段杀，Lean 只认证幸存者。

## 一、阶段 0：工具与表达准备（2–4 周）

| 任务 | 产出 | 说明 |
|---|---|---|
| 定义「维度签名」Schema **v0（最小版）** | YAML/JSON 模板 | 起步字段从严收敛，宁少勿多（见下方"Schema 最小完备性"） |
| 定义「桥」文档格式 | 模板 | 源域、目标域、桥接前提列表、正向演绎链、双闭环状态、维度变化类型标注、实证锚点 |
| 建立**半形式化中间层**规范 | 写作模板 + 示例 | 结构化伪代码 + 范畴论图表（交换图 / String Diagrams）+ 显式前提列表；位于自然语言与 Lean 之间 |
| 选定形式化底座 | Lean 4 + Mathlib 环境 | 仅用于认证幸存桥；桥 = 显式 `axiom`，演绎链 = `theorem` |
| 搭最小 LLM 流水线 | 提取脚本 | 文献 → 维度签名（半自动，人工校对） |
| 制定独立性判定规则 | 评审规范 | Lean 中新概念可从旧结构 `def` 出来 → 非新维度；不可还原的独立 `def`/`axiom` → 候选维度 |

### Schema 最小完备性（阶段 0 重点实验）

- v0 字段从严收敛（建议 4–5 个）：核心对象、核心关系、**独立区分清单（维度）**、典型定理、反例边界；
- "不变量"与"成立条件"极易混淆——第一周用经济学三案例做提取测试，重点观察：**哪些字段被机器匹配真正用到**；
- 砍掉冗余字段，保持最小完备；Schema 本身按"表达量变化 vs 表达维度变化"标准迭代——加字段必须证明它带来新的独立区分能力。

**阶段门槛**：任意两篇论文能稳定转成维度签名；字段集收敛稳定；签名间维度差异可被机器指认。

## 二、阶段 1：单样本试点（1–2 个月）★ 关键里程碑

**试点选题：信息几何 ↔ 热力学**（备选：信息几何 ↔ 统计学习）

**漏斗式执行（廉价淘汰 → 昂贵认证）：**

- **第 1–2 周（半形式化层）**：
  1. 各提取 10–15 个核心命题的维度签名；
  2. 手动走三机制，产出候选桥（预期 10–20 座）；
  3. 每座桥用**交换图 + 显式前提列表**完成双闭环的逻辑推演；
  4. 在此层完成第一轮淘汰——不写一行 Lean（预期砍到 3–5 座）。
- **第 3 周起（Lean 认证层）**：
  5. 仅对 Top 3–5 高价值桥投入 Lean 4：桥接前提显式 `axiom`，正向演绎 `theorem`，机器验证双闭环；
  6. 独立性检验：标注维度变化类型，判定新区分能力 vs 表达量变化；
  7. 幸存桥做实证/数值锚定。

**go/no-go 门槛**：存活 ≥ 2 座"双闭环通过 + 独立性成立 + 有实证锚"的桥；或明确产出负结果（淘汰率与产出结构本身也是交付）。

## 三、阶段 1.5：历史语料验证（可与阶段 1 并行，2–4 周）

检验**猜想本身**：重大理论创新 = 表达空间的维度演化？

**方法：概念网络拓扑指标为主，时间切片词向量为辅。**

1. 选取 3–5 个公认创新节点（牛顿 1687、达尔文 1859、爱因斯坦 1905/1915、香农 1948……）；
2. 对创新前后各时间切片的科学文本建**概念共现网络**，测拓扑指标：介数中心性、结构洞变化、社区结构重组、新增独立连通分量；
3. 辅助证据：按时间切片训练的 Word2Vec / GloVe（**不使用现代大模型 Embedding 作为主要证据**——它携带训练语料的后见之明）；
4. 判据：创新后是否出现新的独立区分方向（网络结构上可测的维度新增/分化/重组）。

**方法论保留（已知张力）**：跨切片词向量对齐（orthogonal Procrustes 等）预设了维度数不变，与"维度演化"假设有内在冲突。因此拓扑指标唱主角，词向量只做辅助；对齐误差本身也可作为"维度变化"的间接信号记录。

**go/no-go**：语料上站不住 → 猜想降级为"方便的比喻"，计划保留工程管线、放弃理论主张。

## 四、阶段 2：管线半自动化（2–3 个月）

- 匹配算法以"维度对齐"为目标函数（关系结构对齐而非词汇相似，Gentner 式）；
- 泛化/迁移/组合做成显式算子，每个算子带结构化接受条件；
- **半形式化层升级为自动淘汰器**：交换图一致性 + 前提列表完备性检查；
- Lean 自动形式化辅助（Mathesis 类流水线）只服务认证层，人工审"桥接前提诚实性 + 语义漂移"。

## 五、阶段 3：成规模开采（持续）

- 建「维度签名库」，覆盖矿脉：信息几何 / 热力学 / 统计学习 / 博弈论 / 因果推断 / 优化 / 变分原理；
- 批量产桥 + 批量杀桥（漏斗比例预期 20 : 3 : 1）；
- 桥谱报告双轴组织：桥型（维度变化五类）× 等级（诺特级/实证级/约定级/修辞级）；
- 二阶桥实验（元化）：对"桥的分类学"本身做一次三机制演绎。

---

## 六、质量标准（全阶段适用）

一座桥要"成"，必须同时满足：

1. **表达完整**：桥接前提全部显式，无隐藏假设；
2. **双闭环通过**：两端特化还原出各自已知定理（半形式化层初筛 + Lean 终审）；
3. **逻辑一致**：组合后无矛盾；
4. **独立性成立**：产出旧表达无法充分表示的新区分能力；
5. **锚点**：至少一端有实证/数值支撑；两端皆为纯数学则要求可证明。

## 七、主要风险与对策

| 风险 | 对策 |
|---|---|
| 桥多为噪声（表面相似） | 结构对齐只认关系；半形式化层廉价淘汰前置 |
| 形式化成本浪费在噪声桥上 | 漏斗式执行：Lean 只认证 Top 3–5 |
| 桥接前提变成"想当然" | `axiom` 显式化 + 逐条评审；约定级公示 |
| 自动形式化语义漂移 | 人工审签名与形式化语句一致性 |
| "独立维度"判定停留直觉 | Lean 可还原性给操作定义；此判定规则本身是要建的桥 |
| Schema 字段冗余/混淆（不变量 vs 成立条件） | 第一周经济学案例实测字段使用率，最小完备迭代 |
| 跨时间词向量对齐预设维度不变 | 拓扑指标为主、词向量为辅；对齐误差另行记录为信号 |
| 猜想可证伪、可能被语料推翻 | 阶段 1.5 专门验证；推翻则降级为工程管线 |
| 战线过长 | 各阶段 go/no-go 硬执行，负结果也算交付 |

## 八、第一周就能做的事

1. 用经济学三案例（正确即完备 / 正义即效率 / 微积分迁移）跑 Schema v0 提取测试，记录**字段使用率**，砍冗余；
2. 同时把三案例各画一张**交换图 + 显式前提列表**，练半形式化中间层；
3. 信息几何和热力学各列 5 个"必收命题"清单；
4. 建仓库骨架：`/signatures` `/bridges` `/semiformal` `/lean` `/corpus` `/reports`；
5. 起草「独立性判定规则」v0（半页即可）。

## 附：项目第一性原理

> 用《原理的演绎》的算子，检验《维度演化》的猜想。
> 正向是方法论，负责从无到有；反向是演绎与实验，负责验收。
> 桥在两端闭环处成真，在独立性处值钱。
> 廉价杀桥，昂贵认证——Lean 是勋章，不是流水线。
