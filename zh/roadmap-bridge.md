# 「原理桥」挖掘计划 · 路线图 v2

> **一句话定义**：用《原理的演绎》的算子（泛化/迁移/组合），检验《表达空间的维度演化猜想》，
> 产出是"桥"，副产品是对猜想本身的证实或修正。

---

## 〇、核心概念（两篇文档的合流）

- **表达空间**：可表达的事物、关系、边界及其高阶结构构成的空间。
- **表达维度**：能够独立表达和区分事物及其关系的结构方向。
- **桥**：两个维度签名之间的结构保持映射，其产出是一次维度变化。
- **三机制算子**：泛化 / 迁移 / 组合，作用于表达空间。
- **维度变化类型**（桥的分类标签）：
  - 维度新增：出现此前无法独立表达的新区分方向（如科斯→正义，"交易成本"成为独立测量维度）
  - 维度分化：混合方向被拆开（如相对论把"同时"拆为参照系相关维度）
  - 维度重组：已有维度间关系重排（如牛顿统一天上/地上的运动）
  - 维度合并：旧维度被高阶理论吸收（如牛顿力学成为广义相对论特例）
  - 元化：表达对象上升到表达方式/生成规则本身（X → I(X)）

## 〇′、三大原则（全计划适用）

1. **表达重于演绎**——桥的质量取决于维度签名的表达质量。
2. **正向产桥，反向杀桥**——双闭环特化还原是核心质检。
3. **桥接前提必须显式**——宁可 `axiom` 丑，不许隐含假设藏。

---

## 一、阶段 0：工具与表达准备（2–4 周）

| 任务 | 产出 | 说明 |
|---|---|---|
| 定义「维度签名」Schema | YAML/JSON 模板 | 字段：核心对象、关系、不变量、成立条件、**能做出哪些独立区分（表达维度清单）**、典型定理、反例边界 |
| 定义「桥」文档格式 | 模板 | 源域、目标域、桥接前提列表、正向演绎链、双闭环状态、**维度变化类型标注**、实证锚点 |
| 选定形式化底座 | Lean 4 + Mathlib 环境 | 桥 = 显式 `axiom`，演绎链 = `theorem` |
| 搭最小 LLM 流水线 | 提取脚本 | 文献 → 维度签名（半自动，人工校对） |
| 制定独立性判定规则 | 评审规范 | 什么算"新维度"vs"表达量变化"：Lean 中若新概念可从旧结构 `def` 出来 → 非新维度；不能还原的独立 `def`/`axiom` → 候选维度 |

**阶段门槛**：任意两篇论文能被稳定转成维度签名，签名之间的维度差异可被机器指认。

## 二、阶段 1：单样本试点（1–2 个月）★ 关键里程碑

**试点选题：信息几何 ↔ 热力学**（备选：信息几何 ↔ 统计学习）

理由：两边都有熵、散度、自然梯度、变分结构，同构线索已知但未被成规模开采；数学工具（Fisher 信息度量、勒让德变换）两边现成，形式化成本低。

执行步骤：

1. 各提取 10–15 个核心命题的维度签名（人工 + LLM）；
2. 手动走三机制，产出候选桥（预期 10–20 座，多数是噪声）；
3. 每座桥写成 Lean：桥接前提显式 `axiom`，正向演绎 `theorem`；
4. **双闭环检验**：桥两端各特化还原回本领域已知定理，还原失败即淘汰（预期存活 2–4 座）；
5. **独立性检验**：幸存桥标注维度变化类型，判定是新区分能力还是表达量变化（后者降级或淘汰）；
6. 幸存桥做实证/数值锚定（哪怕只是数值实验）。

**go/no-go 门槛**：存活 ≥ 2 座"双闭环通过 + 独立性成立 + 有实证锚"的桥；
或明确产出负结果（管线的淘汰率与产出结构本身也有交付价值）。

## 三、阶段 1.5：历史语料验证（可与阶段 1 并行，2–4 周）

检验**猜想本身**：重大理论创新 = 表达空间的维度演化？

1. 选取 3–5 个公认创新节点（牛顿 1687、达尔文 1859、爱因斯坦 1905/1915、香农 1948……）；
2. 对创新前后的科学文本做语义轴 / 嵌入空间分析；
3. 检验创新后是否出现新的独立区分方向（维度新增/分化/重组的可测证据）。

**go/no-go**：若语料上站不住，整个框架降级为"方便的比喻"，计划只保留工程价值（管线照跑，但放弃对猜想的理论主张）。

## 四、阶段 2：管线半自动化（2–3 个月）

- **匹配算法以"维度对齐"为目标函数**：关系结构对齐而非词汇相似（Gentner 式），LLM 提取 + 图匹配；
- 泛化/迁移/组合做成**显式算子**，每个算子带结构化接受条件；
- Lean 端接入自动形式化辅助（Mathesis 类流水线），人工只审"桥接前提是否诚实 + 形式化语义是否漂移"；
- 淘汰器自动化：双闭环特化 = 机器可查的实例化测试；独立性 = 可还原性测试。

## 五、阶段 3：成规模开采（持续）

- 建「维度签名库」，覆盖矿脉：信息几何 / 热力学 / 统计学习 / 博弈论 / 因果推断 / 优化 / 变分原理；
- 批量产桥 + 批量杀桥；
- **桥谱报告按双轴组织**：桥型（维度变化五类）× 等级（诺特级/实证级/约定级/修辞级），定期发布；
- **二阶桥实验（元化）**：对"桥的分类学"本身做一次三机制演绎，看能否发现桥型之间的桥。

## 六、质量标准（全阶段适用）

一座桥要"成"，必须同时满足：

1. **表达完整**：桥接前提全部显式，无隐藏假设；
2. **双闭环通过**：两端特化还原出各自已知定理；
3. **逻辑一致**：组合后无矛盾（Lean 保证）；
4. **独立性成立**：产出旧表达无法充分表示的新区分能力（非表达量变化）；
5. **锚点**：至少一端有实证/数值支撑；两端皆为纯数学则要求可证明。

## 七、主要风险与对策

| 风险 | 对策 |
|---|---|
| 桥多为噪声（表面相似） | 结构对齐只认关系不认词汇；双闭环强制淘汰 |
| 桥接前提变成"想当然" | Lean `axiom` 显式化 + 逐条评审；分类为"约定级"并公示 |
| 自动形式化语义漂移（形式化了 A，说的是 A′） | 人工审签名与形式化语句的一致性——Lean 帮不了这一步 |
| "独立维度"判定停留在直觉（猜想最大软肋） | 用 Lean 可还原性给出操作性定义；此判定规则本身就是一座要建的桥（表达维度 ↔ 形式系统的独立性/不可定义性） |
| 猜想本身是可证伪的经验命题，可能被历史语料推翻 | 阶段 1.5 专门验证；被推翻则计划降级为工程管线，放弃理论主张 |
| 战线过长、样本不足 | 阶段 1 / 1.5 的 go/no-go 硬执行，负结果也算交付 |

## 八、第一周就能做的事

1. 把《原理的演绎》的三个经济学案例（正确即完备 / 正义即效率 / 微积分迁移）填成前 3 份维度签名 + 桥文档，并标注维度变化类型（练 Schema，当场检验分类学好不好用）；
2. 信息几何和热力学各列 5 个"必收命题"清单；
3. 建仓库骨架：`/signatures` `/bridges` `/lean` `/corpus` `/reports`；
4. 起草「独立性判定规则」v0（哪怕只有半页）。

## 附：项目第一性原理

> 用《原理的演绎》的算子，检验《维度演化》的猜想。
> 正向是方法论，负责从无到有；反向是演绎与实验，负责验收。
> 桥在两端闭环处成真，在独立性处值钱。
