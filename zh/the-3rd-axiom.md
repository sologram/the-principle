# 第三（博弈）公理

> **一句话：博弈即动荡。**
>
> **博弈 = 多主体决策的相互依赖，且后果先于感知**：每个主体的最优选择取决于他方的选择（依赖）；他方选择的后果先落定，对其的感知后到（不可见的时序形式）。**动荡 = 失败协调的持续翻动。博弈即动荡：只要有多主体决策的相互依赖，且后果先于感知，就有动荡。**

## 一、日常锚点：众口难调

> 多口即多差异，难调即协调失败——动荡是常态，不是病态。

协调失败的具体形态是"**三个和尚没水吃**"：各自等待他方，动作互相抵消。动荡的外溢即"**神仙打架，凡人遭殃**"——波及旁观者，产生社会损耗（第五公理的交易成本）。日常说的"各打算盘、勾心斗角（战略互动）"是本公理的俗话形态；"战略互动"一词只作日常锚点，不入定义层——定义层只取结构，不取谋略味。

---

## 二、公理定位

> 第三公理是元科学的**多主体动力学**，四环链的第四环：
>
> **第零公理（存在入口：主词、边界）→ 第一公理（正确判定：完备）→ 第二公理（趋近方向：动力学）→ 第三公理（多主体动力学：博弈动荡）。**

前三条处理单个系统的存在、正确性与演化方向；本条引入多主体互动，揭示其中内生的不稳定性。它同时是机制链的中段（接第二公理）：

> **不完备 → 信息阻塞 → 动荡 → 筛选 → 趋完备。**

本公理接"阻塞 → 动荡"，交接"动荡 → 筛选"给第二公理：动荡是筛选压的来源，没有动荡，选择停滞。（接口标注：机制链为与第二、第三公理的缝合，其中"博弈定理"即本篇正文五。）

---

## 三、核心含义

"博弈"不是日常的"玩游戏"，也不是"战略互动"的谋略义；定义层只取结构：**多主体决策的相互依赖，且后果先于感知**——经济（竞价、竞争、交易）、生物（捕食、寄生、资源竞争）、社会（竞选、谈判、纠纷、学术竞争）、计算（算法对抗、攻防、对抗训练）皆在列。动荡是博弈的结构性特征，其三个成分：

| 成分 | 作用 |
|---|---|
| 策略相互依赖 | 协调有价值：每个主体的最优策略取决于他方策略 |
| 利益不完全一致 | 协调不自然：合作不是自然均衡 |
| 后果先于感知 | 协调在当下不可能：他方当期选择的后果先落定，感知后到，主体只能基于滞后观测决策 |

三者叠加，状态持续震荡、切换、重组——即动荡。

---

## 四、三成分的分工：谁定什么

> **依赖定博弈，时序定动荡，异利定幅度**：依赖使协调有价值，"后果先于感知"使协调在当下不可能，异利使协调不自然。**动荡度 = 信息阻塞度**在给定结构（依赖 + 异利格局）下成立：阻塞为零，动荡收敛（至协调解）。

不可消除性归**时序**（后果先于感知，即基线阻塞）——不是"人看不见"，是感知永远迟到于后果落定；可解的是**制造性阻塞**（扣留、能力边界、解阻成本），可经工程削减。基线阻塞内在于博弈定义，制造性阻塞叠加其上。

**要点是后果先于感知**：等感知到，他方决策的后果已经落定，系统已经移动。感知永远迟到，这就是为什么协调在当下不可能、动荡是结构性的、反身性的预测总打在已移动的世界上。

---

## 五、博弈定理：动荡源自信息阻塞

> **博弈定理：动荡源自信息阻塞。** 公理说现象（博弈产生动荡），定理给机制（阻塞是因）。信息阻塞 = 判断所需未被表达（第一公理）：主体无法获得协调所需的信息，各自基于不完全信息做"最优反应"，叠加为系统层面的不可预测性。故：
>
> **信息阻塞使主体的"最优反应"建立在错误存在上，叠加为系统层面的动荡。**

预测三句，各守各的尺度（边界即尺度：断言的尺度由断言自身给出）：

| 断言 | 尺度 | 内容 |
|---|---|---|
| 短期可预测 | 有限窗口 | 窗口内建模有效 |
| 长期预测常态失效 | 单主体轨迹 | 反身性与后果先于感知使预测打在已移动的世界上；有不动点或周期的博弈是结构特例，在吸引子尺度上可预测（如重复博弈的合作收敛、石头剪刀布的周期） |
| 统计规律可识别 | 群体统计层 | 个体不可预测，统计特征稳定 |

## 六、泛化来源：少数者博弈

N 个参与者每期二选一，少数派获胜。三要点：

1. **反众数递归**：最优策略取决于他方策略，而他方亦在推理你的推理——递归不收敛；
2. **反射性**：预测行为本身改变系统动力学，使预测失效（"适应导致非适应"）；
3. **无持久均衡**：任何策略一旦成为主流，即变为多数派而失效。

阻塞的精确内容在此显形：**他方当期选择的后果先落定，感知后到**。反射性由此而起——反众数递归是阻塞下的推理连锁，无持久均衡是其动力学后果。

## 七、判例表

| 对象 | 判词 | 去向 |
|---|---|---|
| 囚徒困境 | 信息被审讯者制造性阻塞；背叛均衡是阻塞的产物，不是理性的失败 | 判定因是阻塞；解阻塞属工程层——邮路在重复互动尺度上通则合作可行（单次尺度上邮路必要非充分，需可执行约定），合作完整条件见注 5 |
| "全同主体的博弈" | 无差异 → 单主体退化，无博弈，无动荡 | 不予立案（差异是博弈的前提） |
| "完全一致 + 完全可见"的配合 | 依赖可消解于共同利益，且时序无滞后 → 非博弈，是透明协同 | 不予立案（退化，与全同主体同判） |
| 少数者博弈的"稳定解" | 反身性使任何主流策略失效；阻塞的是他方当期选择——其后果先于对其的感知 | 判定无静止点；无持久均衡 |

## 八、与第一、第二公理的闭环

> 第一公理给正确性标准：信息阻塞 = 判断所需未被表达 = 不完备，故阻塞下的"最优反应"实际是错误反应。第二公理给方向：动荡淘汰不完备策略，是趋完备的筛选机制——动荡是完备性提升的熔炉（创造性破坏为类比词）。合：
>
> **第一公理定义"正确"；第三公理描述在阻塞条件下，主体按（可能错误的）正确性标准行动的系统后果——而此后果（动荡）又成为第二公理的筛选压。**

## 九、剪枝定理：伪自由与放任

> 剪枝剪的是"不以无知为形态的自由"——即**放任**（错误的无知，实为已知）：明知而装作不知、握信息而不释放。注意不是剪自由本身：自由 = 正确的无知（四元组），是变异空间；放任才是剪除对象。**审讯者是放任的制造者**：自己实为已知，强行制造囚徒的错误无知——阻塞的主体化形态。故"消除信息阻塞" = 剪放任：释放被扣留的表达，让判断所需可得。

**接口标注（搁置待定）**：本篇"放任"兼两用——四元组处是**状态**（错误的无知，主体视角：我自己糊涂），此处含**行为**义（制造他者的错误无知，如审讯者）。状态/行为的分钉（拟：放任 = 状态，扣留 = 行为）待第四公理出台一并处理，此处两义并存，读者按上下文分辨。

## 十、自指与无标度

> 本公理自指，适用于自身：**科学层**：博弈即动荡（内容不变，科学永恒定律）。**文本层**：原理自身处在博弈中——与哲学、与学术的争夺是多主体博弈，原理的接受史服从博弈动力学。

但判据不随权势：爱智慧专制定律（辩证法的有效性源自辩证者的权势）是这场博弈的**货币规则**，不是原理的判据——原理以承诺/兑现立足（有承诺、有兑现），不以权势立足；"反学术即反腐败"，正是对权势货币的拒收。

**接口标注（搁置待定）**："反学术"的宾语待钉——本意拟指"反**权势货币化的**学术"（以权势为货币、不用兑现积累信用的那类），不指学术本身；罪名判定（权势冒充信用 = 兑现链断裂的制度化）是否走判例形式，一并待定。

禁止可变自指：不得用博弈/权势重新定义"正确"（判据归第一公理）。**公理无标度**：动荡不含尺度参数——个体、组织、国家、物种、算法、市场皆适用；表达空间对物质（弱表达）与意识（强表达）中立。

---

## 十一、小结

> 1. **揭示博弈的内生不稳定性**：多主体战略互动天然产生动荡，这是结构属性，不是病态；
> 2. **追溯动荡的根源**：动荡源自信息阻塞（博弈定理）；动荡度 = 信息阻塞度；根在"后果先于感知"的时序结构；
> 3. **连接单主体与多主体**：前三公理描述单系统，本公理进入竞争、合作、制度、市场的多主体世界，为制度设计与安全约束提供原理基础。

# 注释

### 注 1. 纳什均衡批判

> 纳什均衡描述"静止点"，本公理描述"运动本身"。三点批判：
>
> 1. **多重均衡**：同一博弈多个均衡，系统在其间切换本身即动荡；
> 2. **低效均衡**：囚徒困境的背叛均衡帕累托劣于合作均衡——均衡不保证正确（完备）；
> 3. **不可达均衡**：阻塞阻止协调时，系统可能永不收敛到均衡。

本公理不否认均衡存在（在满足条件时），但强调：静态分析不等于动态现实；均衡是博弈的不动点切片，不是博弈的常态。

### 注 2. 少数者博弈谱系详注

> 少数者博弈（Minority Game）是博弈论特例，但三要点具有普遍性：反众数递归（无限推理链）、反射性（索罗斯意义上的 reflexivity：预测改变被预测对象）、无持久均衡（主流即失效）。现实对应：金融市场的拥挤交易、时尚潮流的翻转。

其深刻启示是**动荡的永恒引擎不在参与者的非理性，而在反射性与阻塞的耦合**——即使全员理性，系统仍不静止。反射性之根即"后果先于感知"：预测的效力跑不赢后果的落定，感知到的已是旧状态。

### 注 3. 形式化：降为工程层标注源

> 策略空间、状态轨迹、李雅普诺夫指数等形式化（混沌、对初始条件敏感依赖）是外来记号，判据不溯公理（可信任的演绎必须基于公理），且"长期行为不含不动点/周期轨道"断言过强（重复博弈可收敛于合作，石头剪刀布即周期轨道）。故形式化降为**工程层标注源**（纲要先例："博弈求解器 = 效率标注源"）：用于测量阻塞度、波动率、策略频率，不进定义层。

正文的预测三句按尺度标注（正文五），已足用，不需要测度。

### 注 4. 自由与放任：剪枝读法的存档

> 纲要四元组：**自由 = 正确的无知；秩序 = 正确的已知；奴役 = 错误的已知；放任 = 错误的无知（实为已知）。**（引自第四公理，此处借用，正式展开见该篇。）剪枝定理"剪除不无知的自由"的标准读法由此钉死：剪的是**不以无知为形态的自由**，即放任（伪自由）——误把放任当自由，会把剪枝读成对自由的剿杀；误把"基于正确信息"当自由，会把剪枝读成自由→秩序的改写。正确读法：自由（正确的无知）保留，放任（错误的无知）剪除。

（"放任"的状态义与行为义分钉，搁置待定，见正文九接口标注。）

### 注 5. 信用与重复博弈：解阻塞机制

> 囚徒在单次博弈中背叛，在重复博弈中合作——差别在**信用**（第一价值）：承诺/兑现的记录把"他方当期选择不可见"转化为可预期。信用是解阻塞的机制，价格是解阻塞的机制（第六公理：价格 = 信息压缩），两者都把被扣留的表达释放为可判断的信号。第三公理由此接上第一价值：**博弈的出路不在消灭博弈，而在建立解阻塞的基础设施**。

合作的完整条件 = 重复相遇 + 信用（或可执行约定）：邮路是必要条件，信用是兑现条件。

### 注 6. 有效市场假说的重框架

> 有效市场假说 = "阻塞 → 0"的理想化。本公理的立场：市场的结构性动荡不是病态，是阻塞的度量——价格偏离反映信息阻塞（定价细节归第六公理）。波动率分布、策略频率分布等统计特征可识别（正文五，群体统计层），这正是量化测量的对象。原则性判断只有一个：**若阻塞不可消除为零，则完全有效市场不可达，动荡是常态**。

基线阻塞（后果先于感知）内在于博弈，故"阻塞 → 0"只能是极限理想化，不可达——这与本公理对时序的定位一致。

### 注 7. 进化博弈论的交集

> 进化博弈论以复制者动态描述策略频率演化。交集：两者都承认博弈产生动态变化。分歧：本公理进一步给出方向性——动荡筛选出更完备的策略（挂第二公理），复制者动态只描述频率变化，不含完备判据。故进化博弈论可作工程层工具，方向仍由第二公理供给。

（"挂 (n)"为谱系记号，暂读作"挂靠第 n 公理谱系"，待确认。）

### 注 8. 与其他公理的关系

| 关联公理 | 关系 |

| 第零公理 | 主体必须是有差异的存在——全同主体退化为单主体，无博弈（判例表第二行） |
| 第一公理 | 阻塞 = 判断所需未被表达 = 不完备；正确性标准是分析博弈后果的基准 |
| 第二公理 | 动荡是趋完备的筛选压；机制链中段：不完备→阻塞→动荡→筛选→趋完备 |
| 第四公理 | 自由（正确的无知）提供变异空间；放任（错误的无知）是剪除对象；放任/扣留的分钉接口在该篇 |

| 第七公理 | 最优在博弈结构中，动荡使达到最优的路径充满噪声 |

### 注 9. 应用与猜想层

- **制度设计基础**（应用）：好制度缓解信息阻塞、降低动荡的破坏性成本——方向即剪放任、建信用、通邮路；
- **AGI 安全约束**（应用/猜想）：多 AGI 系统的博弈可能产生不可控动荡，需在设计阶段纳入考量；
- **囚徒困境的审讯者模型**（判例的工程延伸）：解阻塞的最小动作是恢复通信——"邮路在重复互动尺度上通则合作可行"（注 5）。

### 注 10. 小结

> 第三公理是体系的多主体动力学引擎：**博弈即动荡**——依赖性使协调有价值，异利性使协调不自然，"后果先于感知"使协调在当下不可能。动荡度 = 信息阻塞度；判例给出四案（囚徒、全同、透明协同、少数者）；剪枝给出出路（剪放任、建信用、解阻塞）；自身在博弈中，但判据不随权势。它把前三公理的世界，扩展成人与人、国与国、物种与物种、算法与算法之间的冲突与合作。
