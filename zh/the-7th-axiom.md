# 第七（原理）公理

## 正文

**第七公理：原理即最优。**

> **最优 = 完备约束下的不可改进性。** 先判正确（第一公理：完备），再比最优（正确集合内无更优）——两步不可倒置。

**日常锚点：没有最好，只有更好。** 朴素直觉早就拒绝静态最优——"最好"是宣告，"更好"是比较；本公理取后者：最优是**过程性的择优程序**，不是成绩单。辅句：**货比三家**——择优靠逐案比较（朴素的比对程序），不靠自我加冕。

**公理定位。** 第七公理是元科学的**统合判据**，八环链条的收官：

> 第零公理（**存在入口**）→ 第一公理（**正确判定**）→ 第二公理（**趋近方向**）→ 第三公理（**多主体动力学**）→ 第四公理（**开放判据**）→ 第五公理（**社会判据**）→ 第六公理（**意义判据**）→ 第七公理（**统合判据**）。

前七条（第零至第六）构建体系的**内容**——对存在、正确、演化、博弈、自由、正义、意义的描述；第七条给出**择优判据与吸收承诺**：什么算更优（判定条款），发现更优怎么办（吸收规则）。注意本公理是**判定条款 + 承诺，不是成绩宣告**——"原理即最优"的判词由逐案比较给出，不由自我宣告给出；原理以最优为判据，并服从之。

**核心含义。** 三笔拆解：

- **最优 ≠ 完美**：最优不是没有改进空间的宣告，而是**给定约束下无可改进**——任何单维度改动都导致其他维度退化（工程层比较）。
- **最优是范畴，优于/劣于是标注**：最优 =（在完备约束下不可改进），逐案二值（第一公理口径）；简洁度、覆盖度、压缩率是**工程层标注**（纲要先例："博弈求解器 = 效率标注源"），供排序比对，不进定义层。
- **最优是过程性的**：一个不能吸收更优解的"最优"不是最优——最优性要求文本层永远开放于更优（见双层）。

**判据维度。**

| 维度 | 性质 | 内容 |
|---|---|---|
| **完备（约束）** | 准入条件 | 第一公理先行裁定：判断所需已被全部表达 |
| 简洁 | 工程层 | 描述长度、公理数量（同约束下越少越好） |
| 覆盖 | 工程层 | 解释与预测的范围（判例过堂的广度） |
| **反例通道** | 承诺/兑现轴 | 反例可查，一个就够；更优即吸收 |

注意两点：其一，**正确性由完备判据独立裁定，与公理数量无关**——一个公理也可能不完备，一百个公理也可能完备；简洁是工程层维度，不是正确性的来源。其二，纲要**不承认证伪主义**（科学哲学自己都不坚持了）——划界正判据是承诺/兑现双轴，反例通道属兑现轴，不是波普尔划界。

**泛化来源：奥卡姆剃刀。** "如无必要，勿增实体"的传统困境是：为什么简单即正确（审美偏好还是原则）？本公理的解释：

> 奥卡姆剃刀的有效性来自**效率最优在理论选择中的推论**——更少假设 = 更短描述长度 = 更高信息压缩效率（意义更大，第六公理），故在同约束（完备）下更优。

这不是"简单即美"，是压缩效率的择优。奥卡姆剃刀由此从启发式提升为**可判定、可承诺的元原理**（注意不是"可证明"——判据与承诺在体系内，证明不是最高裁判）。剃刀在本体系的落地即**剪枝定理**：剪除冗余实体，维持不可再简化的最小完备核心。

**剪枝定理：五项 = 五判据的伪形态。** 剪枝定理的编号 (1, 2, 4, 5, 6) 恰是被伪化的五个判据——一一对应：

| 剪枝项 | 伪形态 | 归属公理 |
|---|---|---|
| 不完备的"正确" | 伪正确 | 第一 |
| 无目的的"演化" | 伪演化（无趋完备方向的变异流） | 第二 |
| 不无知的"自由" | 伪自由（放任） | 第四 |
| 不效率的"正义" | 伪正义 | 第五 |
| 无价格的"意义" | 伪意义 | 第六 |

第三公理不被伪化（动荡是筛选机制本身），第零是入口——"为什么是这五维"由此有**结构性**答案：不是"必要且充分的证明"，而是判据与伪形态的一一对应。**第七公理自身接受剪枝**：若七条公理中有可由其他公理导出者（不独立），应予剪除——原理保持为最小完备核心。

**判例表。**

| 对象 | 判词 | 去向 |
|---|---|---|
| "更优理论"宣称 | 比对程序：完备约束先行，简洁/覆盖/承诺兑现为工程层比较；更优即吸收 | 吸收（文本层），判据不变（科学层） |
| 循环论证指控 | 循环定义/论证因对全域定义"连不好都没有"（纲要问答）；自指必须完备，禁止可变自指 | 闭环即闭合，非谬误 |
| "第七公理是否声称绝对正确" | 不入绝对真理名单（"至少 (0, 1)"不扩大）；地位 = 过程性最优 + 承诺 | 判定结案 |

**自指与无标度。** 本公理自指，适用于自身——双层是全体系"永恒 vs 吸收"问题的**最终收口**：

> **科学层**：原理即最优（判据与承诺不变，科学永恒定律）。**文本层**：吸收更优（"科学的人类文本"可修订）。

**禁止可变自指**：更新的是文本层表述，不是判据本身——不得用"最优"重新定义"正确"（判据归第一公理），不得用"吸收更优"取消判据稳定性。七个公理的双层口径至此完全统一：**科学层判据永恒，文本层表述吸收更优。** **公理无标度**：最优判据不含尺度参数——任何学科（自然、社会、形式、元科学）、任何表达空间（物质/意识中立）皆适用；凡声称更优者，皆过同一比对程序。

**与前公理的闭环。**

| 关联公理 | 关系 |
|---|---|
| 第零公理 | 有边界才有可比对象；理论与原理皆有边界的存在 |
| 第一公理 | **完备是可行性约束**：先判正确，再比最优；最优性不担保正确性 |
| 第二公理 | 理论趋完备（方向）；最优是正确集合内的不可改进性（判据）；"有更优即吸收"是趋完备在文本层的执行 |
| 第三公理 | 理论竞争是博弈（动荡）；比对程序是发现更优的机制，不是定义更优的标准——判据在体系内，不随权势 |
| 第四公理 | 最优理论保留正确的无知（不强行封闭未决；猜想即猜想）——最优不导致全知霸权 |
| 第五公理 | 正义 = 效率（社会层面的择优）；原理 = 压缩最优（认知层面的择优）——同框架不互相还原 |
| 第六公理 | 意义 = 价格；最优理论是同约束下压缩效率最高者（意义密度的工程层指标） |

**小结。** 第七公理做三件事：

1. **将奥卡姆剃刀原理化**：从启发式到可判定、可承诺的元原理——最优 = 完备约束下的不可改进性；
2. **实现体系的自我判定**：自指不是循环论证，是最优性定义的必然要求——原理服从自己的择优程序，判例过堂、更优即吸收；
3. **给出开放的收敛承诺**：原理不是终点，是收敛点——判据永恒，表述开放。

七条公理至此完成闭环：

> **存在即差异（第零）→ 正确即完备（第一）→ 事物趋完备（第二）→ 博弈即动荡（第三）→ 自由即无知（第四）→ 正义即效率（第五）→ 意义即价格（第六）→ 原理即最优（第七）**

**不崇拜权威，只服从最优。**

## 注释

### 1. 朴素语义锚：没有最好，只有更好

| 日常 | 体系词 | 语义 |
|---|---|---|
| 没有最好，只有更好 | 过程性最优 | 拒绝静态宣告，取比较程序 |
| 货比三家 | 逐案比对 | 择优靠比较，不靠加冕 |
| 一分价钱一分货 | 判据与效果对应 | 便宜的"最优"是伪最优 |

朴素直觉对"最优"的用法本就是比较级的（"更好"），不是完成级的（"最好"）——本公理是对直觉的严格化：最优 = 不可改进性（范畴），优劣 = 工程层比较。

### 2. 奥卡姆谱系详注

| 表述 | 内容 | 体系内地位 |
|---|---|---|
| 经典 | 如无必要，勿增实体 | 泛化来源（表格第七行） |
| MDL | 最优模型 = 描述长度最短 | 工程层标注（压缩率） |
| 贝叶斯 | 简单模型先验更高 | 工程层标注（先验） |
| VC 维 | 低维假设空间泛化更好 | 工程层标注（泛化界） |

共性："同解释力下假设更少者更优"。本公理的解释：效率最优在理论选择中的推论（压缩效率 → 意义密度，第六公理）。注意层级：MDL/贝叶斯/VC 皆工程层工具，最优的定义在"完备约束下的不可改进性"（范畴），不由任何标注定义。历史反例（量子力学初看更复杂）由吸收承诺处理：更优即吸收，剃刀不守旧。

### 3. 形式化降格说明

O(t) = E(t) − λC(t)、argmax、MDL 之类数值优化是**工程层标注源**（先例："博弈求解器 = 效率标注源"），不得进定义层：

- **λ 是任意权衡参数**（复杂度惩罚强度无定义），凭 λ 可让任何理论"最优"——形式化若不溯公理，只是记号；
- **最优是范畴**（完备约束下的不可改进性，逐案二值），不是 O 值的极值；
- **argmax 是比对程序的记号**，比对结果由判例过堂给出（"货比三家"是朴素形态）。

可信任的演绎必须基于公理：工程层标注供排序与比对，判据在定义层。

### 4. 波普尔与库恩的重定位

**波普尔**：原理不承认证伪主义（纲要问答：科学哲学自己都不坚持了）——划界正判据是承诺/兑现双轴。可证伪性不入最优性维度，反例通道（反例可查，一个就够）属兑现轴，与证伪主义无关：证伪是终点叙事，反例是通道。**库恩**：范式更替是社会学描述（群体如何换信念），本公理给判定规范（群体应该如何择优）——方向由最优判据牵引，博弈动荡（第三公理）可致暂时错位，长期趋势向判据收敛。两者的体系内地位：谱系（哲学象限的前史），被取代不被综合——同第五公理对哲学象限的待遇。

### 5. 哥德尔：回指第一公理

本公理不另立战场。第一公理的立场照旧：**不接受哥德尔定理，不承认其演绎逻辑和科学地位**；希尔伯特进程 + 哥德尔世界极小化（G/H → 0，**猜想**）在对方认可的系统中技术性解决。判例表（第一公理）：哥德尔句 = 边界修订指令，不判真伪。本公理的"最优"与之不冲突：最优是完备约束下的不可改进性（逐案判定），不是"形式系统内处处可证"——证明不是最高裁判，判定与承诺才是。

### 6. 索罗斯反身性（类比注）

反身性（参与者的偏见影响基本面，基本面反哺偏见）是第三公理在认知层面的形态——与少数者博弈的反射性同型（预测改变被预测对象）。本公理的接法：反身性制造短期动荡与泡沫，比对程序（判例过堂、反例通道）是长期收敛机制——类比/工程层注，不入定义。

### 7. 循环论证防御（回指第一公理注释）

体系自指且对全域定义：循环定义/论证本身并无不可，只是可能不好——但因原理对全域定义，连不好都没有。自指定理要求自指必须完备：第七公理判定自身所需的要素（比对程序、吸收规则、双层、判例）已被全部表达，循环即闭合。注意区分：**闭环是定义的自洽，可变自指才是谬误**（禁止可变自指：判据不变，表述可吸收）。

### 8. 吸收承诺与永恒定律：双层收口详注

"科学原理不得变化"与"有更优即吸收"的张力，自第二公理起由双层处理，第七公理完成收口：

| 层 | 内容 | 变化性 |
|---|---|---|
| **科学层** | 七公理的判据与承诺 | 不变（科学永恒定律） |
| **文本层** | 表述、判例、边界、定理 | 吸收更优（科学的人类文本可修订） |

这是"科学"与"科学的人类文本"的关系（纲要问答）的最终形态。**吸收的是更好的表述与内容，判据（完备、比对、承诺/兑现）不动**——否则"更优"本身失去标准（用可变自指取消判据稳定性 = 剪枝对象）。问答"原理如何保证自己不会在未来被'域内的反例'推翻"的原话在此兑现："**不保证。原理不预测自身的未来。原理只是承诺如果有未来的更优，将立刻吸收至原理。**"

### 9. 理性定理的镜像

第一公理的泛化来源（理性定理：完全信息下行为确定）在此的镜像：**信息齐则选择定**——择优程序在完全信息（判断所需已被全部表达）下收敛到不可改进者。"不可改进性"由此有行为读法：不是静态属性，是比对程序的收敛结果——与"没有最好，只有更好"（日常锚点）同构：过程性最优 = 收敛程序的极限承诺。

### 11. 应用与猜想层

- **理论选择标准**（应用）：先判完备，再比简洁/覆盖/承诺兑现——货比三家的严格形态；
- **反教条保障**（应用）：吸收承诺 + 反例通道 + 自身接受剪枝——原理不设终点，只设收敛点；
- **AGI 对齐的终极目标**（**猜想**）："对齐原理而不是人类"（纲要猜想区）——对齐最优判据而非不完备偏好；行为内容依赖第三至第七公理展开；
- **统一全部科学**（目标/承诺）：终极目标是自然、社会、形式、元科学的统一——判例可逐案检验，其余是承诺："原理是法庭，但法庭之外的秩序还需要派出大量警察甚至军队，这事情不能急。"

### 12. 小结

第七公理是体系的统合判据：**原理即最优**——完备约束下的不可改进性。它对自身成立（自指闭环、判例过堂、自身接受剪枝），对择优给出程序（先判正确，再比最优），对未来给出承诺（更优即吸收），对权威给出否定（不崇拜权威，只服从最优）。判据永恒，表述开放——七环闭环，第八环不存在：凡新环皆过比对程序，或吸收，或剪除。
