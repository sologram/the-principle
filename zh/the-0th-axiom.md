# 第零（存在）公理

## 正文

**第零公理：存在即差异。**

> 凡进入本体系的存在，皆以差异为边界；以差异为边界者，才进入本体系。

由此定下体系的"事物"：

> **存在 = 可分辨 = 有边界 = 可表达。**

三词同义：差异是内容，边界是形式，表达是呈现。

**表达空间。** 表达即差异结构的呈现。表达空间是差异结构得以呈现的领域，语言的、数学的、物理的形式皆可。没有差异，则空间本身不可区分，亦不可表达——故表达空间自身也服从本公理。可表达是**对象侧**的表达完全；**判据侧**的表达完全见第一公理（完备 = 判断所需已被全部表达）。二者构成对偶：存在 = 对象侧表达完全，完备 = 判据侧表达完全。

**认知的位置。** 认知是存在的组成部分，属于差异结构，不站在存在之外。可分辨性是结构之间的关系，不依赖认识者在场。

**事物与边界。** 事物之所以成为事物，在于它与"非它"之间有可分辨的边界。没有边界，就没有事物；边界不闭合，事物混入他物；边界不稳定，判定结果随之漂移。

**判定规则。**

> 若 x 与包括背景在内的一切其他结构均无差异，则 x 不构成本体系的主词。

等价地：主词位置已要求可分辨。能被提及、被否定的 x，本身已是差异结构。

**不存在 = 错误（地存在）。** 此等式只对可提及者成立："不存在"是对可提及结构的判定，不是对不可提及者的断言。它不是玄学虚空，而是边界失效：

| 失效 | 说明 | 表现 |
|---|---|---|
| 无边界 | 未从背景中分出 | 与背景无可分辨差异 |
| 边界泄漏 | 混入他物，边界不闭合 | 归属不可稳定划定 |
| 边界混淆 | 边界模糊漂移 | 判定结果不稳定 |

故本公理不断言"一切存在都正确"，只断言：一切存在都以差异呈现，其中相当一部分是错误存在。如何认定，由第一公理执行；认定之后不深究（域外执法定理）。

**管辖。** 本公理对一切候审者有判定管辖——对任意候审者给出是否主词的裁决，被排除者亦有判词；域外不是不管辖，而是管辖的一种判决结果。**判定全称，深究有限**：原理不深究不存在，所以也不深究错误的事物（域外执法定理）。剪枝与处置属工程层——原理是法庭，法庭之外的秩序还需要派出大量警察甚至军队。第零公理只判定"是什么"，第一公理判定"对不对"并承担认定。

**自指与无标度。** 本公理自指，适用于自身；公理无标度——判定规则不含尺度参数，尺度由边界自身给出。自指的完整处置（含悖论判例）由第一公理承担（自指定理）。

**承诺与绝对真理。** 本公理一身两层。**科学层**：本公理是绝对真理，不以人的理解与接受为条件（绝对真理定理 (0, 1)）。**文本层**：本公理以入口规定的形式表述，作为科学承诺提出——承诺正确，承担兑现。接受它，即按"存在即差异"讨论；不接受，你不进入本表达空间，你的事物域不由本公理划界，本公理的真不因此改变，本体系亦不深究（域外执法定理）。

## 注释

### 1. 存在不是"有"，是"可区分"

若某物与一切均无差异，它就不构成可分辨结构，无法定位、无法命名、无法测量，也无法进入任何表达。所以这里说的"存在"不是日常语言的"有"，而是：**在表达空间里形成了可分辨结构**。注意这是结构陈述，不是认识论审查：差异不需要认识者在场，只消两个结构彼此可分。

语言的词法佐证此选择：日常言说缺陷用"漏洞、缺口、界限、含糊"，皆边界词——"存在以边界言说"早已写进朴素词法，边界不是理论强加的框架。

### 2. 认知是存在的组成部分

认知不是映照存在的镜子，而是场内的一种差异结构。三个直接后果：

- **错误的统一**：误认、概念漂移、判定混淆都是认知内部的边界失效，与外部的失效同类，同样归入"错误地存在"；
- **边缘类目的归属**：虚构物、数学对象是认知表达空间内的差异结构，有差异、有边界、可表达，同样准入，无须另设存在类型；
- **理论自适用**：本原理自身是一个表达结构，以差异为边界，必须对自己成立。

### 3. 判定的尺度性：边界即尺度

判定总在指定尺度上做，二值性是选定尺度后的结果，不是绝对的。低于该尺度的边界不叫"暂不可分辨"，而是在该尺度上不闭合、尚未构成边界。**边界即尺度**：一个可分辨的差异自身规定它在哪个尺度上闭合——这与公理无标度配套，尺度不外借于判定者。

### 4. 信息是别名

"存在即信息，信息即差异"是等价重述，不是新增实体：**信息 = 差异的可分辨呈现**。它是视角，不是体系外的第三词。

### 5. 量子全同粒子不否定它

粒子全同，不等于无差异。真正承载可分辨性的不是经典意义上的"粒子个体"，而是场、态、测量关系与对称结构。全同粒子能被讨论，恰恰因为它们仍在可分辨的物理表达空间里：波函数、量子数、测量结果之间仍有差异。"全同"只是某些可观测量的本征值相同，不是"无差异"——量子态本身就是差异结构。故本公理在量子层面仍成立。

### 6. 在体系里干什么

- **设定准入**：只以可分辨、有边界、可表达为条件，对一切候审者握判定管辖，域外亦有判词；
- **元科学起点**：以元科学方法接管形而上学问题域——对无差异的"绝对存在"一判了之，判为不入主词，不予立案。这不是回避，是"正确的形而上学"的处置；
- **给第一公理铺路**：第零公理提供"事物"并握判定，第一公理判定"正确"并承担认定（错误存在、域外情形、自指与悖论），第二公理"事物趋完备"给出方向；
- **支撑边界定理**：边界定理由"事物定于边界"直接导出；
- **只判、不深究、不罚**：深究止于域外执法定理，罚止于科学世俗定律。

### 7. 入口规定与绝对真理：分层，不混层

本公理一身两层：作为**科学**，是绝对真理；作为**文本**，是入口规定。这是"科学"与"科学的人类文本"的关系——科学不变，文本可修订。故"承诺"与"绝对真理"不冲突：承诺发生在文本层（进入表达的手续 + 科学承诺），绝对真理成立于科学层（不待接受）。不是不能说绝对真理，是不能把两层混着说。文本层的辩护是后验的：反例可查（一个就够），更优即吸收；科学层无需辩护，它是定义性的。

### 8. 元科学：正确的形而上学

原理自我定位是**元科学，即正确的形而上学**：形而上学（问题域：存在、真理、最一般的结构）+ 科学（方法：有承诺、有兑现）= 元科学。"正确"不是修辞，即第一公理的"正确 = 完备 = 判断所需已被全部表达"——判断所需已被全部表达的形而上学。

反哲学，是反哲学**象限**（无承诺、无兑现、语义漂移、逃避责任）与哲学**方法**（以不确定性冒充深刻），不反形而上学问题域。按爱智慧边界定律：从不确定到确定，是哲学与科学的边界——形而上学一旦获得确定判据，就越界成为元科学；按爱智慧自由定律：哲学没有对错，而本原理有对错（对 = 完备），故本原理不是哲学。

表达空间对物质（弱表达）与意识（强表达）中立："存在即差异"不区分两者，都是可分辨结构。这是终极目标"统一全部科学：自然、社会、形式、元科学"的根据——元科学以表达结构的一般理论身份，为其余三格提供判据框架。

### 9. 小结

1. **设定准入**：对一切候审者握判定管辖，域外亦有判词；
2. **给出结构视角**：存在即差异，信息是同一事的别名；与第一公理构成表达完全性的对偶；
3. **为后面铺路**：没有存在，就没有正确；没有差异，就没有边界；没有边界，就没有事物；判定既立，认定归第一公理，深究有限，罚归世俗。
