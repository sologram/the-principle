## 1. A Question That Is Avoided

Gödel's incompleteness theorems are usually stated as: no formal system that is sufficiently strong, consistent, and recursively axiomatized can exhaust all arithmetical truth.

There is a question inside this formulation that is rarely confronted head-on:

**What exactly is "all arithmetical truth"?**

The standard logical answer: it is the set of all arithmetical sentences that are true under the standard model of the natural numbers, written Th(ℕ). But this answer is itself given in the metalanguage, not within the object system. Inside the object system there is no definition of "true" — only a definition of "provable."

So the real structure of Gödel's theorem is:

- Within the object system F, one can only speak of "provable" and "unprovable."
- Only in the metalanguage M can one speak of "true" and "false."
- The theorem says: F cannot exhaust Th(ℕ).

But Th(ℕ) is defined by M, not by F. So Gödel's theorem is a **meta-theorem** about F, not an arithmetical truth within F.

This point is almost always erased in popular accounts. Once it is erased, the theorem becomes a vague assertion that "mathematical truth transcends formal systems," which is then wheeled out to argue that the human mind is not mechanical, that God exists, and to defend postmodern science. That is abuse.

But even setting aside abuse, even purely within mathematical logic, there is a deeper question of levels:

**Which level does Gödel's theorem itself belong to?**

If it belongs to the object level, then is it itself an arithmetical truth? If it is, why is it not trapped by the very "inexhaustibility" it describes? If it does not belong to the object level, then where does it stand? Is that "outside" the final one?

The standard logical answer: it belongs to the meta-level; and if the metatheory itself is formalized, it too is bound by Gödel's theorem — there is no final "outside." This infinite hierarchy is not a contradiction; it is structure.

But this answer carries a consequence:

**No final system can survey all of truth. There is always an "outside," always a higher meta-level.**

This is taken as the profound conclusion of Gödel's theorem. But it can also be read as something else: **the orthodox community's monopoly on the "outside."** Whoever defines "true," defines "provable," defines "metalanguage" — that one holds orthodoxy.

## 2. The Problem of the Power to Define

The proof of Gödel's theorem rests on a set of premises:

1. The separation of truth from provability.
2. The legitimacy of self-referential construction.
3. The metalanguage's ability to talk about the object language.
4. Standard-model semantics.

These four are not logical necessities; they are **choices of definition**.

Change the definitions, and Gödel's theorem no longer applies.

For example, if "true" just is "provable," then the phrase "true but unprovable" is ill-formed. The Gödel sentence cannot be constructed, because it depends on the separation of "true" from "provable" for the sentence "this sentence is unprovable."

Or again: if self-referential construction is forbidden, then the diagonal lemma is invalid, and the Gödel sentence cannot be generated.

Or again: if the metalanguage is not recognized as a level independent of the object language, then the proof of Gödel's theorem cannot even get off the ground.

These are not logical impossibilities; they are **choices of definition internal to the system**.

The problem: the mainstream mathematical logic community treats these choices as "mathematical necessity" rather than "one strategy of definition." Any system that does not accept these choices is therefore pronounced "non-standard," "unorthodox," "not mathematics."

**This is politics.**

So RSI is no longer "an attempt to approach truth," but **self-unfolding under the axioms**:

**This is the true core of RSI: not compute, not algorithms, but the power to define truth and provability.**
