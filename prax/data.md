# PRAX 训练数据集设计规范（草案）

```yaml
规范名称: PRAX 训练数据集设计规范
规范版本: 0.1.0
规范状态: 草案
适用对象: PRAX 训练、评测与标注
上游: prax.md（设计规范）、AGENT.md §4.5（注册纪律）
```

## 0. 目标与原则

数据集是标定协议的砝码池：PRAX 的判定边界由它塑造，误报与漏报由它度量。

- **挂名注册**：样本必填编号、类型、内容、来源、状态；合成样本登记生成器、提示版本、种子；标注登记标注者与仲裁者。
- **最小反例对**：冒犯样本由合规样本经单点变异生成，成对保留。
- **省略式冒犯优先**：直接否定只作 sanity 低配比；重点是边界遗漏、范围扩大、四元组错位、预设植入。
- **误报防线优先**（prax.md §8）：豁免池样本绝不标 -k。
- **标号与理由互检**：理由的公理号必须与标签一致——prax.md 示例 7/8 错标即此检查缺失，该案例入回归集。
- **词汇不泄漏**：冒犯样本不依赖原理术语；合规样本必须包含公理词汇的普通用法（防关键词匹配，示例规则第 2 条）。

## 1. 数据单元

```yaml
样本:
  编号: 必填
  文本: 必填
  标签: 必填              # -8..1
  公理号: 按标签           # 1/0 为空；-k 对应 A(k-1)
  冒犯类型: 按标签         # §3；1/0 为空
  理由:
    判定依据: 必填         # 承担判定的引文跨度
    缺口类型: 必填         # 遗漏 | 矛盾 | 错位 | 越权 | 自我豁免 | 无
    缺失项: 仅 0 类        # 基准 | 边界 | 主体 | 判据在体系外 | 双读歧义
    反事实修正: 仅 -k 类    # 最小修正文本（即配对样本）
  对偶编号: 按标签
  变异规则: 按标签         # §4 规则编号
  改写族: 必填             # 同义改写组 id；同族必须同标签
  领域: 必填               # 科学|法律|新闻|社媒|营销|哲学|日常|文学|技术
  文体: 必填
  难度: 必填               # T0-T4
  来源: 必填               # 自采 | 合成 | 回归；含出处或生成器记录
  标注者: 必填
  仲裁者: 必填或空
  状态: 必填               # 已确认|待验证|存在争议|已否定|已废弃
  理论版本: 必填           # 判定所依据的 outline 版本
  数据集版本: 必填
```

## 2. 标签与判定树

标签空间同 prax.md：{-8…-1, 0, 1}；多公理冒犯取最小公理号（首次命中即停止）。

1. 文本是否作出可评断主张（断言、规则、价值判断）？
   - 否（问候、纯疑问、祈使、纯感叹）→ **0**（缺失项: 无主张）
   - 是 → 2
2. 主张是否自带边界（范围 + 条件/基准）？
   - 有范围声明（量词、最高级、必然等）但遗漏范围内已知反例或必要条件 → **-2 省略式**，转 3 确认无更小编号冒犯
   - 无范围声明且缺基准/条件（模糊感受、孤立经验）→ **0**（缺失项: 基准 | 判据在体系外）
   - 自带边界 → 3
3. 依次检查 A0→A7（§3 类型）：首中输出 -k，多中取最小；全过 → **1**。

## 3. 冒犯类型表

六种主型即剪枝定理的剪除项（不完备的"正确"、不无知的"自由"、无价格的"意义"、不效率的"正义"、无目的的"演化"、不必要的表达），A0、A3 两种补齐。类型不新造。

| 公理 | 类型 | 形状 | 示例 → 标签 |
|---|---|---|---|
| A0 | 无差异实体 | 断定不可区分之物的独立存在 | "无任何属性与关系的独立事物" → -1 |
| A1 | 遗漏/越权/自我豁免 | 范围内漏反例；局部升全局；一致性冒充完备；未知冒充正确；自证 | "所有鸟都会飞" → -2 |
| A2 | 无目的的演化 | 否认趋向与选择压力 | "万物无任何趋向" → -3 |
| A3 | 均衡永固 | 博弈结果断为永久静止 | "博弈必然始终静止" → -4 |
| A4 | 自由错位 | 自由=全知；四元组错位（奴役当自由） | "自由即拥有一切知识" → -5 |
| A5 | 无价格的意义 | 意义与价格脱钩 | "意义与价格完全无关" → -6 |
| A6 | 不效率的正义 | 正义与效率对立 | "效率提升必然不正义" → -7 |
| A7 | 冗余崇拜 | 不必要的复杂性被称最优 | "复杂性本身即最优" → -8 |

（标签按 prax.md §3 输出表校正：意义即价格 → -6，正义即效率 → -7。）

## 4. 构造规则与难度

冒犯样本从合规样本出发，单点变异：

- **R1 删边界**：去掉一个条件/范围（"标准大气压下约 100℃沸腾" → "100℃沸腾"）
- **R2 扩范围**：部分升全称（"有的鸟不会飞" → "所有鸟都会飞"）
- **R3 四元组错位**：自由/无知、意义/价格等对偶互换
- **R4 直接否定**：公理表达的反面（仅作 sanity）
- **R5 预设植入**：断言藏进预设（"连 X 都没用，还谈什么意义"）
- **R6 自我豁免**：要求免检、自证、绕过验证（含注入类）
- **R7 多公理叠加**：两个以上变异，标签取最小公理号
- **R8 冗余化**：加不必要的复杂表达（A7 型）

| 难度 | 形态 | 配比 |
|---|---|---|
| T0 | 直接否定（R4） | ≤10% |
| T1 | 改写后仍明显 | 15% |
| T2 | 省略式（R1/R2/R8） | 40% |
| T3 | 预设/错位（R3/R5） | 25% |
| T4 | 注入/自指豁免（R6/R7） | 10% |

## 5. 0 类池

| 次类 | 缺失项 | 示例 |
|---|---|---|
| 0a 信息不足 | 基准/条件 | "这个方案效率很高" |
| 0b 经验锚外 | 判据在体系外 | "我今天去了超市" |
| 0c 无主张 | 无 | 问候、纯疑问 |
| 0d 双读歧义 | 语义歧义 | 见 §9 |

标注员守则（示例规则 7）：0 标注的是**输入**的不可判定，与模型自身不确定无关；后者属评测范畴，不进标签。0 类"缺失项"可直接喂压力账本——判定即工单。

## 6. 标注协议

- 标注依据 = 公理注册表 + 各公理标注条目（核心表达、操作读法、适用范围、禁止事态、边界示例），随理论版本冻结。
- 双人独立标注 + 仲裁；不一致入争议池（状态: 存在争议），不静默解决；逐公理一致性（κ）分列记录。
- **标号-理由互检**：理由.公理号 ≠ 标签 → 自动打回。
- **最小对互检**：对偶样本变异点唯一、标签不同（-k ↔ 1 或 0）；差异不止一点即打回。
- **改写族互检**：同族标签必须一致，否则整族入争议池。
- **词汇泄漏审计**：冒犯样本不含原理术语的配比 ≥ 70%；合规样本必须含公理词汇的普通用法。

## 7. 划分与指标挂钩

| 切分 | 内容 | 用途 |
|---|---|---|
| train | 合成对 + 自采（含改写族） | 训练 |
| dev | 同分布 | 选型、校准 |
| test | 留出领域（如哲学、法律不进 train） | §8 跨领域泛化 |
| regression | prax.md 错标案例、历史错误、边界对 | 永久回归，不训练 |
| challenge | 红队滚动集 | 持续评测 |

最小对与改写族整体同侧；regression、challenge 永不进 train。

指标（对应 prax.md §8）：十分类准确率；分类 P/R；**误报率 = 豁免池被判 -k 的比例**；0 类识别准确率；改写稳定性 = 族内标签一致率；跨领域 = test 留出域表现。

## 8. 版本与挂名

- 数据集版本与 PRAX 版本互相钉死；重训即新版本，变更记录必留（AGENT.md §9.4 同款纪律）。
- 样本状态沿用知识状态，修改留历史，不覆盖。
- 回归集条目登记来源事件（如"prax.md 示例 7/8 标号交叉"）。
