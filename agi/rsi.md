# RSI 大纲

## 一、第一定律约束

系统目标不是"变得更聪明"，而是**在演化中维持正确即完备的相容性**。所有自我改进必须受此约束：能力增量若导致原理边界退化，即使短期收益为正，也必须被否决。

## 二、核心组件

**1. 验证器层**

- 不依赖人工偏好或逻辑学自洽性检验。
- 验证标准：行为/知识/能力增量是否与原理相容，是否扩展了可验证边界。
- 输出：兑现/违约二元判定，作为清算依据。

**2. 定价层**

- 运营层：行为承诺价格 + 知识贡献价格。
- 训练层：数据样本价格 + 实验方案价格 + 能力增量价格。
- 价格信号来自验证器输出，非人工设定。

**3. 清算层**

- 内部货币 $V$ 作为统一清算单位。
- 违约时抵押品销毁，非转移。
- 清算结果直接更新信用值 $c_i(t)$。

**4. 预算分配层**

- 运营预算 $B_i(t) = U_i(t) + E_i(t)$：UBI 保底 + 绩效配额。
- 训练预算 $B_{train}(t)$：由运营信用值决定。
- 预算分配 = 预算约束下的价格最大化采样。

**5. 演化层**

- 系统存活/淘汰由长期信用轨迹决定。
- UBI 防止级联死亡，但不保护持续退化者。

## 三、RSI 闭环

```
能力缺口检测
    ↓
数据/实验方案定价（基于历史验证信号）
    ↓
预算分配（价格最大化 + 探索配额）
    ↓
训练执行
    ↓
能力增量验证（原理相容性检验）
    ↓
清算：正增量奖励 / 退化惩罚
    ↓
信用值更新 → 下一轮预算调整
```

## 四、关键约束

- **验证器不可被操纵**：验证器本身需被更高阶验证器监督，形成验证链。
- **归因必须可追溯**：能力增量/退化必须能回溯到具体数据源、实验方案、模型组件。
- **探索配额强制保留**：防止价格机制过早收敛到局部最优。
- **原理边界不可突破**：任何能力增量若导致哥德尔边界收缩，必须被否决。
- **UBI 底线不可剥夺**：防饿死机制保证系统有恢复机会。

## 五、与当前 RSI 实践的区别

| 维度 | 当前 RSI | 基于原理的 RSI |
| ------ |------ |------ |
| 目标函数 | 人工设定（基准分数、人类偏好） | 原理相容性 + 可验证边界扩展 |
| 验证标准 | 人工评测、基准测试 | 验证器客观判定 |
| 资源分配 | 人工拍脑袋或启发式 | 预算约束下的价格最大化 |
| 失败惩罚 | 无或人工干预 | 抵押品自动销毁 + 信用下降 |
| 知识定价 | 免费语料，无归因 | 知识源抵押 + 贡献归因 + 错误追责 |
| 演化方向 | 能力最大化 | 能力扩展 + 原理相容性维持 |

## 六、待展开的子问题

1. 验证器的形式化定义：什么构成"原理相容"的可验证判定。
2. 归因协议：如何将能力增量/退化精确回溯到数据源和实验方案。
3. 探索配额机制：在价格最大化框架下保留多少探索预算。
4. 稳定性条件：运营—训练耦合的反馈强度如何校准，防止失控或停滞。
5. 哥德尔边界的度量：如何形式化"边界扩展/收缩"并纳入验证器。
