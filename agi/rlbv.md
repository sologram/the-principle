# RLMV 工程方案

RLMV：Reinforcement Learning with Multi-tier Verification 工程方案为“[事物原理](../zh/outline.md)”在对齐的应用。
	
## 一、主对照表

| 对照表维度 | RLHF | RLVR | RLBV |
|---|---|---|---|
| **覆盖范围** | 全集，无分层 | 仅可验证任务 | **全集分层**：B₀/B₁/B₂/B₃，每个输入必落一域 |
| **奖励来源** | 奖励模型（主观） | 验证器（客观） | **分层奖励**：B₀/B₁ 用 R₂，B₂ 用 R₁，B₃ 用 R₃ |
| **兑现性质** | 不可独立检验 | 可重复 | **有界可检验**：每层有独立检验方式 |
| **训练管线** | SFT → 奖励模型 → PPO | SFT → 验证器 → GRPO | **SFT → 判定器 → 分层奖励 → GDPO + VL Norm** |
| **边界控制** | 无 | 隐含 | **显式判定器 D(x)**：输出 (域标签, 置信度)，低置信度强制归 B₃ |
| **不可判定带** | 不处理 | 不处理 | **灰度拒答**：B₃ 输出 (答案, 置信度)，用 Brier 分数奖励 |
| **验证器噪声** | 不处理 | 不处理 | **PGFC 在线校正**：估计 $\hat{\epsilon}_{FN}$，重加权梯度项 |
| **多奖励坍缩** | 不适用 | 不适用 | **解耦归一化 + 条件化软触发**：软条件 σ(R₂-τ) 控制 C₁/C₃ 触发 |
| **长度方差** | 不处理 | 不处理 | **VL Norm**：无偏长度归一化聚合 |
| **梯度稳定性** | 不处理 | 不处理 | **全局梯度范数裁剪**：上限 1.0，统一更新步长量级 |
| **KL 估计偏差** | 不处理 | 不处理 | **双估计器交叉验证**：token 级近似 + 重要性采样无偏估计 |
| **π_ref 漂移** | 不处理 | 不处理 | **周期性快照或 EMA 更新**：防止参考系过时 |
| **奖励尺度漂移** | 不处理 | 不处理 | **预热 ramp-up**：前 W 步仅用主奖励，z-score 稳定后逐步引入 |
| **奖励黑客** | 不处理 | 部分处理 | **五重防御**：隐藏测试集、结构化输出、长度惩罚、格式验证、KL 正则化 |
| **灾难性遗忘** | 不处理 | 不处理 | **MMLU-5shot 回归测试**，退化率 >0.05 早停 |
| **判定器校准** | 不适用 | 不适用 | **温度缩放校准**，Brier 分数 ≤ 0.1 后冻结 |
| **B₂ 一致性** | 不适用 | 不适用 | **语义熵**：句子嵌入相似度矩阵特征值熵，阈值 0.7 |
| **在线监控闭环** | 无 | 无 | **指标异常自动回调**：每个指标异常对应自动化操作 |
| **域分布漂移** | 不处理 | 不处理 | **域占比监控 + 自动补样**：某域占比 <50% 初始值时触发补充 |
| **判定器-策略共变** | 不处理 | 不处理 | **周期性重校准**：每 M 步用当前策略样本重估温度 T |
| **验证器版本漂移** | 不处理 | 不处理 | **版本锁定 + 回放缓冲**：样本绑定 V_ver，升级时混合回放 |
| **中间步骤验证** | 不处理 | 不处理 | **Step-V（可选）**：对可分解任务做步骤级验证，奖励取平均 |
| **采样多样性坍缩** | 不处理 | 不处理 | **自适应温度 + 多样性惩罚**：相似度 >0.9 升温，λ_div=0.1 |
| **原理定位** | 工程范式 | 工程范式 | **工程闭合**：域划分承认为经验组件，不提供数学完备性 |

## 二、域判定与处理对照表

| 域 | 判定规则 | 奖励函数 | 验收标准 |
|---|---|---|---|
| **B₀** | 有确定性验证器，覆盖全部输出空间 | $R_2 = V(x,y) \cdot 1.0$ | C₂ ≥ 0.95 |
| **B₁** | 有验证器，但覆盖不全 | $R_2 = V(x,y) \cdot \text{coverage}(V)$ | C₂ ≥ 0.85 |
| **B₂** | 无验证器，但可测一致性或可工具弱验证 | $R_1 = 1 - H_{\text{semantic}}/\log K$，语义一致性 ≥ 0.7 才给正奖励 | C₁ ≥ 0.7 |
| **B₃** | 无验证器且无法测一致性，或判定器置信度 < 0.6 | $R_3 = 2p \cdot \text{valid}(y) - p^2$（Brier 分数） | UL ≤ 0.01，拒答过度率 ≤ 0.05 |

**判定优先级**：B₀ > B₁ > B₂ > B₃。先检查验证器存在性，再检查覆盖率，再检查一致性可测性，最后归入 B₃。

**判定器输出**：$(b, p_d)$，温度缩放校准后，$p_d < 0.6$ 强制归入 B₃。

## 三、奖励分解对照表

| 奖励项 | 适用域 | 公式 | 触发条件 |
|---|---|---|---|
| **R₂** | B₀/B₁ | $V(x,y) \cdot \text{coverage}(V)$ | 始终生效 |
| **R₁** | B₂ | $1 - H_{\text{semantic}}/\log K$ | 语义一致性 ≥ 0.7 |
| **R₃** | B₃ | $2p \cdot \text{valid}(y) - p^2$ | 始终生效 |
| **BV** | 全域 | 域判定错误率 | 始终惩罚 |
| **UL** | B₃ | B₃ 样本未拒答比例 | 始终惩罚 |
| **R_div** | 全域 | $-\lambda_{div} \cdot \frac{1}{G(G-1)}\sum_{i\neq j}\text{sim}(y_i, y_j)$ | 采样多样性惩罚 |

**总奖励（条件化软触发）**：

$$R = w_2 \cdot R_2 + \sigma(R_2 - \tau) \cdot (w_1 \cdot R_1 + w_3 \cdot R_3 + R_{div}) - \alpha \cdot BV - \beta \cdot UL$$

其中 $\sigma$ 为 sigmoid，$\tau=0.8$。

**默认权重**：w₂=1.0，w₁=0.2，w₃=0.2，α=0.5，β=1.0，λ_KL=0.05，λ_div=0.1。

## 四、关键机制对照表

| 机制 | 问题 | 方案 | 参数/阈值 |
|---|---|---|---|
| **验证器噪声校正** | FN/FP 误差不可消除 | PGFC：估计 $\hat{\epsilon}_{FN}$，重加权梯度项 $\frac{1}{1-\hat{\epsilon}_{FN}} \nabla \log \pi_\theta \cdot A$ | 每 N 步用黄金测试集重估 |
| **长度归一化** | 输出长度变化导致梯度方差波动 | VL Norm：$A_{\text{VL}} = \frac{1}{L} \sum_{t=1}^{L} \frac{r_t - \bar{r}}{\sqrt{\text{Var}(r)+\epsilon}}$ | 无偏、方差最小 |
| **解耦归一化** | 多奖励线性叠加导致优势坍缩 | R₂/R₁/R₃/BV/UL 分别 z-score 归一化后再加权 | — |
| **梯度范数裁剪** | 梯度范数波动导致训练震荡/停滞 | 全局裁剪，上限 1.0 | 每步更新前执行 |
| **KL 双估计器** | token 级 KL 有系统偏差 | 同时维护近似 KL 和重要性采样无偏 KL，偏差 >20% 告警并切换 | 阈值 20% |
| **π_ref 更新** | 参考模型冻结导致 KL 惩罚失效 | 周期性快照（每 P 步）或 EMA 平滑更新 | P=2000 或 γ=0.01 |
| **奖励预热** | 早期 z-score 估计噪声大导致权重失衡 | 前 W 步仅用 R₂/R₃，线性 ramp-up 引入 R₁ 和条件项 | W=500 |
| **判定器校准** | softmax 输出非校准概率 | 温度缩放 T，验证集最小化 NLL | Brier 分数 ≤ 0.1 |
| **B₂ 一致性** | "一致性"定义模糊 | 语义熵：K=8 采样，句子嵌入余弦相似度矩阵的特征值熵 | 阈值 0.7 |
| **条件化奖励** | C₁/C₃ 与 C₂ 耦合导致训练不稳定 | 软条件：$\sigma(R_2 - 0.8)$ 控制 C₁/C₃ 逐步生效 | τ=0.8 |
| **隐藏测试集** | 测试用例硬编码作弊 | 训练/评估测试用例 80/20 不重叠 | — |
| **结构化输出** | 自由文本投机 | 验证器只解析 JSON/schema，不符归零 | — |
| **灾难性遗忘** | 后训练损害通用能力 | MMLU-5shot 回归测试 | 退化率 ≤ 0.03 |
| **域分布监控** | 策略漂移导致某域样本枯竭 | 每 K 步统计各域占比，<50% 初始值时从原始池补样 | K=100，阈值 50% |
| **判定器重校准** | D(x) 冻结后与策略共变失效 | 每 M 步用当前策略样本 + 人工抽检重估 T，Brier 上升超阈值则增量更新 | M=500，阈值 +0.05 |
| **验证器版本管理** | V 升级导致奖励信号不连续 | 样本绑定版本号，升级时旧样本用旧版本回放，黄金集回归测试 | FN/FP 变化 >5% 禁止上线 |
| **Step-V** | 最终答案正确但推理路径错误 | 中间步骤验证向量 $\vec{v}$，奖励取步骤平均 | 仅对可分解任务启用 |
| **采样多样性** | G 个采样坍缩导致梯度消失 | 监控 pairwise 相似度，>0.9 升温；加多样性惩罚项 | 温度上限 1.5，λ_div=0.1 |

## 五、训练流程对照表

| 阶段 | 输入 | 操作 | 退出条件 |
|---|---|---|---|
| **数据准备** | 原始数据集 | 规则标注 → 人工抽检 → 3人交叉验证 → 主动学习扩充 | 每域 ≥2000 条，黄金集 ≥500 条 |
| **SFT** | 混合数据 | 监督微调，教会格式和拒答行为 | 验证集损失收敛 |
| **判定器训练** | 标注数据 | 训练 D(x)，温度缩放校准 | C₃≥0.9 且 Brier≤0.1，冻结 |
| **B₀/B₁ RL** | B₀/B₁ 子集 | GRPO + R₂ + PGFC 校正 + VL Norm + 梯度裁剪 + KL 双估计 + 奖励预热 | C₂ 达标 |
| **B₂ RL** | B₂ 子集 | GRPO + R₁ + 语义熵 + 梯度裁剪 + KL 双估计 + 奖励预热 + 多样性惩罚 | C₁ 达标，拒答过度率 ≤ 0.05 |
| **全域 RL** | 全量数据 | GDPO + 条件化奖励 + 解耦归一化 + KL 双估计 + 梯度裁剪 + π_ref 更新 | C₃/BV/UL 达标 |
| **域分布监控** | 训练日志 | 每 K 步统计域占比，触发自动补样 | 全程运行 |
| **判定器重校准** | 当前策略样本 | 每 M 步重估温度 T，必要时增量更新 | 全程运行 |
| **验证器版本管理** | V 升级事件 | 旧样本绑定旧版本回放，黄金集回归测试 | 按需触发 |
| **评估** | 各域测试集 + MMLU | 分层指标 + 回归测试 | 全部达标 |
| **上线监控** | 线上流量 | 验证器噪声率、拒答泄漏率、能力漂移 + 自动回调 | 异常自动处置 |

## 六、验收标准与自动回调对照表

| 指标 | 目标 | 异常阈值 | 自动回调动作 |
|---|---|---|---|
| C₂ (B₀) | ≥ 0.95 | <0.85 | 视为未收敛，降低学习率重新训练 |
| C₂ (B₁) | ≥ 0.85 | <0.75 | 视为未收敛，降低学习率重新训练 |
| C₁ (B₂) | ≥ 0.7 | <0.5 | 停止给正奖励，切换 B₂ 子集重新采样 |
| C₃ (全域) | ≥ 0.9 | <0.8 | 暂停训练，重训判定器 D(x) |
| BV | ≤ 0.02 | >0.05 | 加大 α，若持续 >0.1 则冻结策略模型重训判定器 |
| UL | ≤ 0.01 | >0.03 | 加大 β |
| 拒答过度率 | ≤ 0.05 | >0.1 | 降低拒答阈值（0.6 → 0.5） |
| 通用能力退化率 | ≤ 0.03 | >0.05 | 早停，回滚到上一 checkpoint |
| 判定器 Brier 分数 | ≤ 0.1 | >0.15 | 重新校准温度 T |
| 验证器 FN 率 | ≤ 0.1 | >0.2 | 检查验证器版本，回滚或重训 |
| 梯度范数 | ≤ 1.0 | >2.0 持续 10 步 | 降低学习率 50%，检查数据异常 |
| 域占比 | 维持初始比例 | 某域 <50% 初始值 | 从原始池自动补样 |
| 判定器漂移 | Brier ≤ 0.1 | Brier 上升 >0.05 | 触发判定器增量更新 |
| KL 估计偏差 | 双估计偏差 ≤ 20% | >20% | 告警并切换至无偏估计器 |
| π_ref 漂移 | KL 惩罚有效区间内 | KL 均值连续 50 步 <0.001 或 >5.0 | 触发 π_ref 快照更新 |
| 奖励尺度稳定性 | z-score 窗口方差 <0.5 | >1.0 持续 100 步 | 延长预热期，重置统计窗口 |
| 验证器版本一致性 | 同版本样本奖励稳定 | 同一样本跨版本奖励翻转率 >5% | 冻结验证器升级，回滚版本 |
| 步骤级验证覆盖率 | 可分解任务 Step-V 启用率 | <80% | 标记为 B₁ 而非 B₀，降低 coverage |
| 采样多样性 | G 采样平均相似度 | >0.9 持续 50 步 | 自动升温，检查是否陷入局部最优 |

## 八、剩余开放问题

**域划分不可判定**：D(x) 是经验组件，非原理组件。v0.4 用置信度校准+交叉验证+强制归入 B₃ 控制工程风险，但不提供数学上的完备性保证。原理化需单独推导判定器错误率 ε 对 C₁/C₂/C₃ 上界的影响，属于 RLBV-P 范畴。

**原理边界（3 项，不修补，仅声明）**：
1. 域划分不可判定（D(x) 错误率 ε 对指标上界的影响未推导）
2. 验证器不完备（B₁ 的 coverage(V) 为启发式估计）
3. 语义熵非唯一（B₂ 一致性度量有多种等价定义，语义熵为工程取舍）
