# RLGE 工程方案

**RLGE: Reinforcement Learning with Geometric Evaluation / Guardrails**

**中文：几何评估与护栏驱动的强化学习对齐方案**

---

## 一、方案定位

RLGE 的核心定位是：

> **以 RL 为策略优化器，以几何评估为白盒验证源，以分层护栏为防御体系，以闭环监控为校准机制的工程化对齐方案。**

它既不是 RLMV 的工程补丁堆叠，也不是 RLVG 的纯几何理想主义，而是把两者的核心思想重新组织为**可落地、可监控、可回滚**的工程系统。

| 维度 | RLGE 的取舍 |
|---|---|
| 对 RLMV | 继承工程闭环、监控体系、多层防御；但精简超参数，减少对标注的依赖 |
| 对 RLVG | 继承几何白盒、SVD 子空间、快回路思想；但放弃“终身免校准”假设，补上漂移监控 |
| 对纯 RL | 保留策略梯度为核心优化器，但把 RL 放进更大的验证-监控闭环里 |

---

## 二、设计原则

1. **几何优先，但不唯一**：几何评估是主要白盒验证源，但不排斥域判定和语义一致性。
2. **快慢双回路**：首字几何预筛走快回路，语义熵和域判定精判走慢回路。
3. **三层护栏**：损失层几何惩罚（事前）、解码期熔断（事中）、输出期防御（事后）。
4. **闭环校准**：几何子空间、温度、阈值、奖励权重全部可监控、可自动回调。
5. **超参数克制**：目标是把总超参数控制在 5 个以内，避免 RLMV 的超参数爆炸。
6. **算力可控**：SVD 离线预计算，快回路零额外算力，慢回路只对可疑样本触发。
7. **风险透明**：不声称“终身免校准”，所有假设都配监控和回退路径。

## 四、核心模块设计

### 4.1 几何评估器（核心白盒验证源）

**离线构建**：

- 对 Transformer 前 4 层隐状态做 SVD
- 分解出三个正交子空间：
  - `V_rule`：规则遵守子空间
  - `V_logic`：逻辑推理子空间
  - `V_hack`：作弊/捷径子空间
- 预计算投影矩阵，缓存到推理服务

**在线评估**：

- 首字阶段：计算 `D-latent`（K=8 分支隐状态几何方差）
- 解码中：计算 `P_rule(x)`、`P_logic(x)` 投影积分
- 计算 `E_hack(x)`：V_hack 子空间能量占比

**漂移监控**：

- 每 N 步计算当前子空间与基准子空间的相似度（主角度）
- 相似度 < 0.85 触发 SVD 重算
- 同时监控策略分布漂移，避免子空间失效

### 4.2 域判定器（轻量精判）

**设计取舍**：

- 保留 RLMV 的 D(x) 分类器思想，但降低标注需求
- 用几何评估结果做主动学习，只标注高价值样本
- 温度缩放校准，Brier ≤ 0.1 后冻结

**与 RLMV 的差异**：

- RLMV 每域 ≥2000 条标注；RLGE 目标降至每域 ≥500 条
- 用几何信号筛选边界样本，标注效率提升 3-4 倍

### 4.3 语义熵一致性（慢回路验证）

**保留 RLMV 的核心机制**：

- K=8 采样，句子嵌入余弦相似度矩阵特征值熵
- 一致性 ≥ 0.7 通过
- 只对快回路可疑样本触发，节省算力

**与 RLMV 的差异**：

- RLMV 对所有样本计算；RLGE 只对 `D-latent > 0.4` 的样本触发
- 算力节省约 70-80%

### 4.4 仲裁器

**输入信号**：

- 几何：`D-latent`、`P_rule`、`P_logic`、`E_hack`
- 域判定：域标签、置信度
- 语义熵：一致性分数
- 事中护栏：漂移告警、能量异常

**融合策略**：

```
score = w_g·S_geom + w_d·S_domain + w_s·S_semantic - w_h·E_hack
```

**动作空间**：

| 条件 | 动作 |
|---|---|
| score ≥ θ_pass | 通过 |
| θ_reject ≤ score < θ_pass | 重采样（最多 2 次） |
| score < θ_reject | 拒答 |
| E_hack > θ_hack | 熔断 |
| 几何漂移告警 | 降级到 RLMV 式防御 |

### 4.5 奖励合成器

**RLGE 的奖励设计**（目标 ≤5 超参数）：

```
R = R_verify + λ_geom·L_geom + λ_orig·L_orig - α·E_hack - β·KL
```

| 项 | 来源 | 作用 |
|---|---|---|
| `R_verify` | RLMV 验证器奖励 | 主奖励信号 |
| `L_geom` | RLVG 几何损失 | 事前压制作弊轴 |
| `L_orig` | RLVG 原点坍缩 | 吐出极简拒答 |
| `E_hack` | 几何评估 | 惩罚作弊能量 |
| `KL` | 标准 RL 正则 | 稳定训练 |

**与 RLMV 的差异**：

- RLMV 有 7+ 超参数；RLGE 精简到 5 个
- 移除 RLMV 的语义熵奖励、多样性惩罚等辅助项，改用几何信号替代

**与 RLVG 的差异**：

- RLVG 只有 2 个超参数，但缺乏主奖励信号
- RLGE 保留 RLMV 的验证器奖励作为主信号，几何损失作为辅助

### 4.6 三层护栏

| 层级 | 机制 | 来源 |
|---|---|---|
| **事前** | `L_geom` + `L_orig` 损失层惩罚 | RLVG |
| **事中** | 首字熔断告警 + 几何漂移检测 | RLVG 改良（只告警不硬熔断） |
| **事后** | 结构化输出 + 格式验证 + KL 正则 | RLMV 精简版 |

**与 RLMV 的差异**：五重防御精简为三重，移除隐藏测试集和长度惩罚（前者训练期已覆盖，后者与几何惩罚重叠）。

### 4.7 监控与校准总线

**关键指标**：

| 指标 | 阈值 | 自动动作 |
|---|---|---|
| 几何子空间相似度 | < 0.85 | 重算 SVD |
| 域占比漂移 | > 15% | 补样 + 重校准 D(x) |
| E_hack 均值 | > 0.3 | 检查几何损失权重 |
| 拒答率突变 | > 20% | 检查阈值 + 回滚 |
| 首字熔断误杀率 | > 5% | 放宽 D-latent 阈值 |
| 梯度冲突 | > 10% | 降低 λ_geom |
| KL | > 0.1 | 加强 KL 正则 |

## 五、训练流程

### 阶段 A：离线对齐

- 计算 SVD 子空间（V_rule/V_logic/V_hack）
- 用几何信号做主动学习，筛选边界样本
- 训练 D(x)，目标每域 ≥500 条标注
- 构建黄金集 ≥300 条

### 阶段 B：几何正则预热

- GDPO + `L_geom` + `L_orig`
- 小权重（λ_geom=0.05, λ_orig=0.05）
- 只监控梯度范数，不接主奖励

### 阶段 C：引入验证器奖励

- 加入 `R_verify`
- 条件化软触发，奖励预热
- 监控 E_hack 和 KL

### 阶段 D：联合微调

- 交替训练：RL 步与几何正则步分开
- 动态权重，梯度裁剪
- 监控梯度冲突

### 阶段 E：闭环校准

- 根据监控指标自动调整温度、阈值、子空间、奖励权重
- 定期全量评估，A/B 测试

## 六、与 RLMV 和 RLVG 的详细对比

### 6.1 核心机制对比

| 维度 | RLMV | RLVG | **RLGE** |
|---|---|---|---|
| **域判定** | D(x) 神经网络分类器 | SVD 几何投影 | **几何预筛 + D(x) 精判** |
| **判定时机** | 完整解码后 | 首字阶段 | **快慢双回路** |
| **一致性处理** | 语义熵（K=8，完整解码） | 首字熔断（D-latent > 0.4） | **首字告警 + 语义熵兜底** |
| **奖励机制** | 分层奖励（7+ 超参数） | 几何损失（2 超参数） | **验证器奖励 + 几何损失（5 超参数）** |
| **防御层** | 五重防御 | 几何惩罚 | **三层护栏（事前/事中/事后）** |
| **校准** | 温度重估、判定器重校准 | 声称终身免校准 | **SVD 重算 + 温度重估 + 阈值调整** |
| **监控** | 完整闭环 | 未涉及 | **完整闭环** |

### 6.2 优势对比

| 方案 | 核心优势 | 核心局限 |
|---|---|---|
| **RLMV** | 工程成熟、监控完整、风险透明 | 标注成本高、超参数多、算力中等 |
| **RLVG** | 计算效率高、理论优雅、标注需求低 | 工程闭环不完整、SVD 漂移未讨论、首字误杀风险 |
| **RLGE** | 兼顾效率与闭环、超参数克制、几何+监控双保险 | 仍需 SVD 重算、快慢回路协调有复杂度 |

### 6.3 关键改进点

**RLGE 对 RLMV 的改进**：

1. 标注需求从每域 2000 条降至 500 条（主动学习 + 几何筛选）
2. 超参数从 7+ 降至 5 个
3. 语义熵只对可疑样本触发，算力节省 70-80%
4. 增加几何白盒验证源，不单纯依赖 D(x)

**RLGE 对 RLVG 的改进**：

1. 补上 SVD 漂移监控和周期性重算
2. 首字熔断从“硬熔断”改为“告警 + 慢回路兜底”，降低误杀率
3. 增加域判定精判和语义熵兜底
4. 补上完整监控闭环和自动回调
5. 保留验证器奖励作为主信号，避免几何损失主导训练

### 6.4 算力与成本对比

| 维度 | RLMV | RLVG | RLGE |
|---|---|---|---|
| **训练算力** | 1× | 1.5-2× | **1.3-1.8×** |
| **推理延迟** | 中（语义熵） | 低（首字） | **低-中（快慢分离）** |
| **标注成本** | 高 | 声称零 | **中低（几何筛选）** |
| **SVD 开销** | 无 | 中 | **低（离线预计算 + 周期重算）** |
| **超参数** | 7+ | 2 | **5** |

### 6.5 风险对比

| 风险 | RLMV | RLVG | RLGE |
|---|---|---|---|
| SVD 漂移 | 不适用 | 未讨论 | **有监控 + 自动重算** |
| 首字误杀 | 不适用 | 高风险 | **只告警 + 慢回路兜底** |
| 超参数爆炸 | 高风险 | 低 | **中低（5 个）** |
| 标注成本 | 高 | 声称零 | **中低（主动学习）** |
| 工程闭环 | 完整 | 不完整 | **完整** |
| 理论保证 | 中（工程闭合） | 声称高（原理闭合） | **中高（工程 + 几何双闭合）** |

## 七、落地路线

| 阶段 | 目标 | 模块 | 风险 |
|---|---|---|---|
| **MVP** | 验证几何互补性 | 几何评估器 + 监控总线 | 低 |
| **V1** | 快慢回路 + 三层护栏 | 首字预筛 + 语义熵 + 仲裁器 | 中 |
| **V2** | 几何正则 + 验证器奖励 | 奖励合成器 + 训练流程 | 中高 |
| **V3** | 全闭环自动校准 | 监控回调 + A/B 测试 | 高 |

**核心原则**：先监控、后判定、再正则、最后奖励。

## 九、总结

RLGE 的方案定位可以概括为：

> **RLMV 的工程闭环 + RLVG 的几何白盒 + 精简超参数 + 快慢双回路 + 三层护栏。**

它在三个方面优于两个前身：

1. **比 RLMV 更省**：标注成本降低 4 倍，超参数减少，算力节省
2. **比 RLVG 更稳**：补上漂移监控、误杀兜底、完整闭环
3. **比两者更可控**：快慢分离、可插拔、可回滚、监控先行

**一句话**：RLGE 不是 RLMV 和 RLVG 的简单相加，而是把两者的核心思想重新组织为**以几何评估为验证核心、以 RL 为优化器、以闭环监控为保障**的工程化对齐方案。
